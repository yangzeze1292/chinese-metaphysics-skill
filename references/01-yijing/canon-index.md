# 经典文献索引 (Canon Index)

> 本文档列出本 skill 中涉及易经的经典文献，包含书目信息、内容概要、版本建议及推荐阅读顺序。所有文献均为历代易学研究的核心典籍，是深入学习易经不可或缺的参考。

---

## 一、核心经典文献

### 1. 《周易本义》

| 项目 | 详情 |
|------|------|
| **作者** | 朱熹（南宋，1130-1200） |
| **成书年代** | 约 1177 年（淳熙四年） |
| **文献性质** | 经学注疏 |
| **版本建议** | 中华书局 2009 年点校本（廖名春点校） |
| **PDF 标识** | `zhouyi-ben-yi` |

**内容概要：**
朱熹《周易本义》是宋代理学易学的集大成之作。朱熹主张"易本卜筮之书"，回归《周易》的原始占筮功能，矫正了王弼以来以义理解易的过度玄学化倾向。全书十二卷，包含六十四卦经传注解、系辞传、说卦传、序卦传、杂卦传。卷首附有《易图》（河图洛书、伏羲八卦次序图、文王八卦次序图等九图）和《筮仪》（蓍草占筮的具体仪式）。

**学术价值：**
- 为宋明理学易学之奠基之作
- 卦变图、变爻规则为后世占断之核心依据
- 恢复了《周易》的象数传统

**核心篇章：**
- 卷首：《筮仪》——蓍草起卦仪式
- 卷首：《易图》——河图洛书、八卦次序图
- 卷一至卷二：上经（乾至离）
- 卷三至卷四：下经（咸至未济）
- 卷七至卷八：系辞传
- 卷九：说卦传
- 卷十：序卦传、杂卦传

### 2. 《周易注》

| 项目 | 详情 |
|------|------|
| **作者** | 王弼（三国·魏，226-249）、韩康伯（东晋）补注 |
| **成书年代** | 约 240 年（王弼注上下经），约 380 年（韩康伯补注系辞等） |
| **文献性质** | 经学注疏 |
| **版本建议** | 中华书局 2011 年《周易注校释》（楼宇烈校释） |
| **PDF 标识** | `zhouyi-zhu` |

**内容概要：**
王弼《周易注》是魏晋玄学易学的代表作，开创了"扫象数、阐义理"的易学新风。王弼以老庄思想解易，提出"得意忘象"的方法论，对后世易学影响深远。注文简练精辟，六十四卦每卦注文往往仅数十字，却能直指核心。韩康伯补注《系辞传》以下诸篇，延续了王弼的义理风格。

**学术价值：**
- 魏晋玄学易学的开山之作
- 从象数易学向义理易学转变的关键文献
- 唐代孔颖达《周易正义》以王弼注为底本，成为科举标准

**核心篇章：**
- 卷一至卷三：上经注
- 卷四至卷六：下经注
- 卷七至卷九：韩康伯注系辞传
- 卷十：韩康伯注说卦、序卦、杂卦

---

### 3. 《周易集解纂疏》

| 项目 | 详情 |
|------|------|
| **作者** | 李鼎祚（唐）集解，李道平（清）纂疏 |
| **成书年代** | 李鼎祚集解约 760 年，李道平纂疏约 1840 年 |
| **文献性质** | 集解注疏 |
| **版本建议** | 中华书局 1994 年点校本（潘雨廷点校） |
| **PDF 标识** | `zhouyi-jijie-zuanshu` |

**内容概要：**
李鼎祚《周易集解》是唐代保存汉易象数学最重要的文献，汇集了自子夏、孟喜、京房、郑玄、荀爽、虞翻至孔颖达等三十余家易说，尤以虞翻、荀爽之说为大宗。李道平《周易集解纂疏》是清人对《集解》最详尽的疏解，逐条考辨各家源流，是研究汉易象数学的必读文献。

**学术价值：**
- 保存了大量亡佚的汉魏易学文献
- 汉易象数学（卦变、爻辰、纳甲、升降等）的核心文献
- 与王弼义理易学形成互补，是研究象数易学的必读之书

**核心篇章：**
- 卷一至卷十七：六十四卦集解及纂疏
- 系辞传、说卦传、序卦传、杂卦传集解及纂疏

### 4. 《周易大传今注》

| 项目 | 详情 |
|------|------|
| **作者** | 高亨（1900-1986） |
| **成书年代** | 1979 年 |
| **文献性质** | 现代注释 |
| **版本建议** | 齐鲁书社 1979 年初版 / 清华大学出版社 2010 年新版 |
| **PDF 标识** | `zhouyi-dazhuan-jinzhu` |

**内容概要：**
高亨《周易大传今注》是近现代易学研究的里程碑式著作。高亨继承乾嘉朴学传统，以训诂考据的方法对《易传》十篇（十翼）进行逐字逐句的注释。全书不涉及占筮应用，专注于文献学意义上的经传解读，注释详实，论断严谨，是理解《易传》哲学思想的最佳入门书。

**学术价值：**
- 现代易学文献学研究的典范之作
- 以训诂方法解读《易传》哲学
- 厘清了《易经》与《易传》的时代差异和思想关联

**核心篇章：**
- 卷一：彖传今注（上）
- 卷二：彖传今注（下）
- 卷三：象传今注（大象传、小象传）
- 卷四：系辞传今注
- 卷五：说卦传、序卦传、杂卦传今注
- 卷六：文言传今注

### 5. 《周易尚氏学》

| 项目 | 详情 |
|------|------|
| **作者** | 尚秉和（1870-1950） |
| **成书年代** | 约 1940 年 |
| **文献性质** | 象数易学专著 |
| **版本建议** | 中华书局 1980 年版 |
| **PDF 标识** | `zhouyi-shangshi-xue` |

**内容概要：**
尚秉和是近代象数易学大家，其《周易尚氏学》以恢复汉代象数易学传统为宗旨。尚氏认为《周易》辞皆由象生，他通过深入研究《焦氏易林》等汉代文献，重新发现了大量失传的易象，使许多历来难解的卦爻辞豁然开朗。全书以象数为核心，每卦先列象数分析，再解释卦爻辞。

**学术价值：**
- 近代象数易学复兴的代表作
- 重新发现大量失传的易象（如半象、覆象、伏象等）
- 对疑难卦爻辞的解读具有独特价值

**核心篇章：**
- 卷一至卷二：上经
- 卷三至卷四：下经
- 卷五：系辞传
- 卷六：说卦传、序卦传、杂卦传

### 6. 《易经杂说》

| 项目 | 详情 |
|------|------|
| **作者** | 南怀瑾（1918-2012） |
| **成书年代** | 约 1975 年 |
| **文献性质** | 通俗讲学 |
| **版本建议** | 复旦大学出版社 1997 年版 |
| **PDF 标识** | `yijing-zashuo` |

**内容概要：**
《易经杂说》是南怀瑾先生在台湾讲授易经的课堂记录整理稿。全书以通俗易懂的语言，深入浅出地介绍了易经的基本知识、卦爻结构、占筮方法及哲学思想。南怀瑾融会儒释道三家，旁征博引，将深奥的易理讲得生动有趣，特别适合初学者入门。

**学术价值：**
- 最佳易经入门读物
- 儒释道三教融通的解读视角
- 丰富的实例和生动的讲解风格

**核心篇章：**
- 易经的基本原理
- 六十四卦概说
- 系辞传解读
- 占筮方法介绍
- 易经与人生哲学

### 7. 《易经新解：天行健》

| 项目 | 详情 |
|------|------|
| **作者** | 曾仕强（1935-2018） |
| **成书年代** | 约 2005 年 |
| **文献性质** | 现代解读 |
| **版本建议** | 陕西师范大学出版社 |
| **PDF 标识** | `yijing-xinjie-tianxingjian` |

**内容概要：**
曾仕强《易经新解》以现代管理学视角解读易经，将古老的易理与现代人生、管理、处世之道相结合。全书以"天行健"的自强不息精神为主线，对六十四卦逐一进行现代语境下的解读，强调易经在当代社会中的实际应用价值。

**学术价值：**
- 现代应用易学的代表性作品
- 管理学与易学的跨学科融合
- 注重实践指导，强调知行合一

**核心篇章：**
- 易经的现代意义
- 六十四卦的管理学解读
- 易经与人生决策
- 乾坤之道与现代领导力

### 8. 《周易参同契集注》

| 项目 | 详情 |
|------|------|
| **作者** | 魏伯阳（东汉，约 2 世纪），集注者多家 |
| **成书年代** | 约 142 年 |
| **文献性质** | 丹道经典 |
| **版本建议** | 仇兆鳌《周易参同契集注》（清）/ 中华书局版本 |
| **PDF 标识** | `zhouyi-cantongqi-jizhu` |

**内容概要：**
《周易参同契》是道教丹鼎派的核心经典，号称"万古丹经王"。全书以周易卦爻、黄老养生、炉火炼丹三者相参同契，故名"参同契"。魏伯阳用易卦符号系统构建了内丹修炼的完整理论体系，将乾坤为鼎炉、坎离为药物、其余六十卦为火候，开创了易学与道教修炼相结合的传统。

**学术价值：**
- 道教内丹学的奠基之作
- 易学在道教修炼中的最高应用
- 对中国古代化学、养生学有重要影响

**核心篇章：**
- 上篇：乾坤坎离四卦为纲，论炼丹的基本原理
- 中篇：六十卦为火候，论修炼的具体过程
- 下篇：综合论述，包含歌诀和口诀
- 五相类：论述五行相生相克与炼丹的关系

**注：** 此书以道教丹道为主，易学为方法论工具。在玄学 skill 中主要用于理解易学在道教修炼中的应用。

## 二、推荐阅读顺序

### 初学者路径

| 阶段 | 书目 | 目标 | 建议用时 |
|------|------|------|----------|
| 第一 | 《易经杂说》（南怀瑾） | 建立整体认知，消除畏难心理 | 2-3 周 |
| 第二 | 《易经新解：天行健》（曾仕强） | 了解现代应用，建立实践感 | 2-3 周 |
| 第三 | 《周易大传今注》（高亨）选读 | 掌握《易传》哲学思想 | 4-6 周 |
| 第四 | 《周易本义》（朱熹） | 学习经典注疏，掌握占筮方法 | 4-6 周 |

### 进阶者路径

| 阶段 | 书目 | 目标 | 建议用时 |
|------|------|------|----------|
| 第一 | 《周易注》（王弼） | 精研义理易学 | 8-12 周 |
| 第二 | 《周易本义》（朱熹）精读 | 掌握宋明理学易学体系 | 8-12 周 |
| 第三 | 《周易集解纂疏》（李道平） | 深入汉易象数学 | 12-16 周 |
| 第四 | 《周易尚氏学》（尚秉和） | 融通象数与义理 | 8-12 周 |

### 专题研究路径

| 方向 | 书目 | 说明 |
|------|------|------|
| 象数易学 | 《周易集解纂疏》+《周易尚氏学》 | 卦变、爻辰、纳甲、升降等 |
| 义理易学 | 《周易注》+《周易大传今注》 | 哲学思想、道器关系 |
| 占筮应用 | 《周易本义》+《易学启蒙》 | 蓍草法、变爻规则、筮仪 |
| 丹道修炼 | 《周易参同契集注》 | 易学在道教内丹中的应用 |

## 四、延伸阅读

### 4.1 出土文献

- **马王堆帛书《周易》**（西汉初年）：1973 年长沙马王堆出土，是最早的周易写本，卦序与通行本不同，附有《二三子问》《系辞》《要》《缪和》《昭力》等失传的易传篇章
- **上海博物馆藏战国楚竹书《周易》**（战国）：2003 年公布，是已知最早的周易文本，仅存 58 支简，含 34 卦
- **清华简《筮法》**（战国）：清华大学藏战国竹简，详细记载了战国时期的占筮方法

### 4.2 工具书

- 黄寿祺、张善文《周易译注》（上海古籍出版社）：最权威的现代译注本
- 朱伯崑《易学哲学史》（北京大学出版社）：系统梳理易学哲学发展史
- 高亨《周易古经今注》（中华书局）：与《周易大传今注》配套，专注经文注释
