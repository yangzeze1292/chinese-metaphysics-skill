# 六十四卦数据库 (Bagua Database)

> 本数据库收录《周易》六十四卦完整信息。前 10 卦（乾至履）含全文，其余卦列关键信息。卦辞爻辞以王弼本为底本，参校朱熹《周易本义》及李鼎祚《周易集解》。

---

## 凡例

- **卦名**：含拼音，便于检索
- **卦序**：通行本《周易》卦序，1-64
- **上下卦**：上卦在下，下卦在上（传统读法：下卦在前，上卦在后）
- **卦象**：Unicode 卦符（䷀—䷿）
- **卦辞原文**：卦名后的总断辞
- **彖传**：孔子所作，解释卦辞的哲学意义
- **大象传**：孔子所作，以卦象推人事
- **六爻爻辞**：初爻至上爻，各条独立
- **核心含义**：现代白话解读
- **关键词**：便于检索匹配

### 第 1 卦：乾 (qián) — ䷀

| 项目 | 内容 |
|------|------|
| **卦序** | 1 |
| **上下卦** | 下乾上乾（乾为天，乾为天） |
| **卦象** | ䷀（六爻皆阳，纯阳之卦） |
| **五行** | 金 |
| **核心含义** | 天道刚健，创生万物，君子以自强不息 |
| **关键词** | 天、健、元、创造、刚健、君子、龙、阳、始 |

**卦辞原文：**
> 乾：元，亨，利，贞。

**彖传：**
> 大哉乾元，万物资始，乃统天。云行雨施，品物流形。大明终始，六位时成，时乘六龙以御天。乾道变化，各正性命，保合太和，乃利贞。首出庶物，万国咸宁。

**大象传：**
> 天行健，君子以自强不息。

**六爻爻辞：**

| 爻位 | 爻辞 |
|------|------|
| 初九 | 潜龙勿用。 |
| 九二 | 见龙在田，利见大人。 |
| 九三 | 君子终日乾乾，夕惕若厉，无咎。 |
| 九四 | 或跃在渊，无咎。 |
| 九五 | 飞龙在天，利见大人。 |
| 上九 | 亢龙有悔。 |
| 用九 | 见群龙无首，吉。 |

**用九（乾卦特有）：**
> 乾卦六爻皆阳，故有用九之辞。见群龙无首，吉——阳刚至极而能柔，群龙并现而不争首，乃天道之最高境界。

1. **检索卦名**：使用 `grep` 按卦名（含拼音）或关键词搜索

3. **按上下卦查找**：查阅"八卦取象速查表"确定各卦组成
