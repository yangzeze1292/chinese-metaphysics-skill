# 理气风水详解

## 概述

理气风水，又称理法派、福建派，为中国风水学两大根本流派之一。理气之学，以时间流转与空间方位的交互关系为研究对象，运用阴阳五行、八卦九星、天干地支等理论工具，推算宅运之旺衰。

蒋大鸿《地理辨正》云："峦头为体，理气为用。"体用合一，方为风水正道。峦头定格局之大小，理气定运程之吉凶。二者相辅相成，缺一不可。

理气风水主要包括三大体系：罗盘使用（二十四山定向）、玄空飞星（时间与方位的动态关系）、八宅风水（命卦与宅卦的配合）。

## 一、罗盘使用

### 1.1 罗盘的基本结构

罗盘（又称罗经、罗庚）是风水师的必备工具，其结构由内而外可分为：

**天池（磁针层）：**
罗盘正中心为天池，内置指南磁针。天池代表太极，为罗盘之根本。

**地盘（正针二十四山）：**
地盘为罗盘最内层的方位圈，以正针（磁北）定向，将圆周分为二十四等份，即二十四山。

**人盘（中针）：**
位于地盘外侧，较地盘后移半位（7.5度），用于消砂——判断周围山体的吉凶。

**天盘（缝针）：**
位于人盘外侧，较地盘前移半位，用于纳水——判断来水去水的吉凶。

### 1.2 二十四山

二十四山是将八个卦位（八卦）各分三山，共二十四山，每山占15度，合计360度。

**二十四山排列：**

| 卦位 | 三山 | 方位 |
|------|------|------|
| 坎（北） | 壬、子、癸 | 337.5°-22.5° |
| 艮（东北） | 丑、艮、寅 | 22.5°-67.5° |
| 震（东） | 甲、卯、乙 | 67.5°-112.5° |
| 巽（东南） | 辰、巽、巳 | 112.5°-157.5° |
| 离（南） | 丙、午、丁 | 157.5°-202.5° |
| 坤（西南） | 未、坤、申 | 202.5°-247.5° |
| 兑（西） | 庚、酉、辛 | 247.5°-292.5° |
| 乾（西北） | 戌、乾、亥 | 292.5°-337.5° |

**二十四山与天干地支：**
- 八天干：甲、乙、丙、丁、庚、辛、壬、癸（戊己属中宫，不入二十四山）
- 十二地支：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥
- 四维卦：乾、坤、艮、巽（即四隅卦）

### 1.3 分金

分金是在二十四山的基础上，进一步将每山分为五等份，每份3度，共120分金。其中可用者仅48分金（旺相分金），其余72分金为孤虚或空亡，不可用。

**分金法则：**
- **旺相分金**：地支山用天干分金，天干山用地支分金，干支相合为旺相
- **孤虚分金**：干支相同或相冲为孤虚
- **空亡分金**：分金落于两山交界处为空亡

**实用分金口诀：**
> 甲壬阳门乙癸良，丙午丁未亦堪当。
> 庚申辛酉真为贵，二十四山仔细详。

**一百二十分金中七十二分金不可用的原因：**
- 分金落空亡者，气不贯通
- 分金犯孤虚者，阴阳不调
- 分金犯差错者，卦位不正

### 1.4 罗盘使用要点

1. **定方位**：将罗盘平放于穴场或宅基中心，待磁针稳定后读盘
2. **避干扰**：远离金属物、电器、钢筋等磁性干扰源
3. **三盘合用**：地盘定向，天盘纳水，人盘消砂
4. **十字天心**：先定中轴线（坐向线），再推周边格局

## 二、玄空飞星

### 2.1 三元九运

玄空飞星以三元九运为时间框架。三元即上元、中元、下元，每元三运，每运二十年，共九运一百八十年。

**三元九运表（近期）：**

| 运 | 起止年份 | 所属卦 | 星 |
|----|----------|--------|-----|
| 上元一运 | 1864-1883 | 坎 | 一白 |
| 上元二运 | 1884-1903 | 坤 | 二黑 |
| 上元三运 | 1904-1923 | 震 | 三碧 |
| 中元四运 | 1924-1943 | 巽 | 四绿 |
| 中元五运 | 1944-1963 | 中宫 | 五黄 |
| 中元六运 | 1964-1983 | 乾 | 六白 |
| 下元七运 | 1984-2003 | 兑 | 七赤 |
| 下元八运 | 2004-2023 | 艮 | 八白 |
| 下元九运 | 2024-2043 | 离 | 九紫 |

**当前（2024-2043年）为下元九运**，九紫右弼星当令，属火，主离卦。离为火，代表文化、科技、美丽、中女、南方等。

### 2.2 飞星盘

玄空飞星的核心是排布飞星盘，包括运盘、山盘、向盘三层。

**飞星轨迹（洛书九宫飞泊）：**
九星飞泊的顺序为：中宫 -> 乾 -> 兑 -> 艮 -> 离 -> 坎 -> 坤 -> 震 -> 巽 -> 中宫

**九宫方位：**

| 巽（东南）| 离（南）| 坤（西南）|
|-----------|---------|-----------|
| 震（东）| 中（中宫）| 兑（西）|
| 艮（东北）| 坎（北）| 乾（西北）|

**排盘步骤：**

1. **排运盘**：将当运之星入中宫，按洛书九宫轨迹顺飞八宫
2. **排山盘**：以坐山之星入中宫，根据阴阳顺逆飞八宫
3. **排向盘**：以向首之星入中宫，根据阴阳顺逆飞八宫

**山星与向星的顺逆飞规则：**
- 山星：坐山对应二十四山中的天元龙/人元龙/地元龙，阳则顺飞，阴则逆飞
- 向星：向首对应二十四山中的天元龙/人元龙/地元龙，阳则顺飞，阴则逆飞

**三元龙阴阳：**
- 天元龙：子午卯酉乾巽艮坤——子午卯酉为阴，乾巽艮坤为阳
- 地元龙：辰戌丑未甲庚丙壬——俱为阴
- 人元龙：寅申巳亥乙丁辛癸——俱为阳

### 2.3 旺山旺向

旺山旺向是玄空飞星的最佳格局，即当运的山星飞到坐山，当运的向星飞到向首。

**旺山旺向的条件：**
- 坐山方有当运山星飞临
- 向首方有当运向星飞临
- 山星在坐山得位，向星在向首得位
- 峦头形势配合理气数据

**九运（2024-2043年）旺山旺向：**
- 九运以九紫星为当运旺星
- 旺山旺向的坐向组合需符合九紫星到山到向
- 具体坐向需结合具体飞星盘推算

### 2.4 上山下水

上山下水是玄空飞星中的凶局，与旺山旺向相反。

**上山下水格局：**
- 当运的山星飞到了向首（山上山）——坐山无气，人丁不旺
- 当运的向星飞到了坐山（水下水）——向首无气，财源不聚
- 山星下水，主损丁；向星上山，主破财

**化解方法：**
- 通过调整门、路、水位来改变纳气
- 利用五行生克化解
- 严重者建议改换坐向

## 三、八宅风水（概要）

### 3.1 东四宅与西四宅

八宅风水将住宅按坐向分为八种宅型，再分为东四宅与西四宅两大系统。

**宅卦分类：**

| 宅型 | 坐向 | 卦位 | 分类 |
|------|------|------|------|
| 坎宅 | 坐北向南 | 坎 | 东四宅 |
| 离宅 | 坐南向北 | 离 | 东四宅 |
| 震宅 | 坐东向西 | 震 | 东四宅 |
| 巽宅 | 坐东南向西北 | 巽 | 东四宅 |
| 乾宅 | 坐西北向东南 | 乾 | 西四宅 |
| 坤宅 | 坐西南向东北 | 坤 | 西四宅 |
| 艮宅 | 坐东北向西南 | 艮 | 西四宅 |
| 兑宅 | 坐西向东 | 兑 | 西四宅 |

**东四宅不可与西四宅混用：** 东四命宜居东四宅，西四命宜居西四宅，此为八宅风水之根本法则。

### 3.2 命卦计算

**命卦计算公式（以出生年份计算）：**

**男性命卦：**
1. 将出生年份各位数字相加，直至得个位数
2. 用11减去该个位数，得命卦数
3. 命卦数对应：1坎、2坤、3震、4巽、5（男为坤）、6乾、7兑、8艮、9离

**女性命卦：**
1. 将出生年份各位数字相加，直至得个位数
2. 用4加上该个位数，得命卦数
3. 命卦数对应：1坎、2坤、3震、4巽、5（女为艮）、6乾、7兑、8艮、9离

**命卦分类：**
- 东四命：坎（1）、离（9）、震（3）、巽（4）
- 西四命：乾（6）、坤（2）、艮（8）、兑（7）

### 3.3 游年八星

八宅风水以游年八星判断各方位吉凶。八星由宅卦翻卦得出。

**八星名称与吉凶：**

| 星名 | 五行 | 吉凶 | 主事 |
|------|------|------|------|
| 生气 | 木 | 大吉 | 旺丁旺财，事业发达 |
| 天医 | 土 | 大吉 | 健康、治病、贵人 |
| 延年 | 金 | 大吉 | 长寿、婚姻、人际关系 |
| 伏位 | 木 | 小吉 | 平稳、安定、守成 |
| 绝命 | 金 | 大凶 | 绝嗣、重病、横祸 |
| 五鬼 | 火 | 大凶 | 火灾、口舌、官非 |
| 六煞 | 水 | 次凶 | 桃花劫、破财、是非 |
| 祸害 | 土 | 次凶 | 疾病、口舌、不和 |

**翻卦法（大游年歌诀）：**
> 乾六天五祸绝延生，坎五天生延绝祸六。
> 艮六绝祸生延天五，震延生祸绝五天六。
> 巽天五六祸生绝延，离六五绝延祸生天。
> 坤天延绝生祸五六，兑生祸延绝六五天。

（注：每句首字为宅卦，后七字依次对应：伏位、六煞、天医、五鬼、祸害、绝命、延年、生气在八个方位的分布。详细解释见`bazhai.md`。）
