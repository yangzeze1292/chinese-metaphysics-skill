# 奇门解盘法

## 一、概述

奇门解盘是奇门遁甲的核心应用环节，通过对已排定的奇门局进行综合分析，推断人事吉凶。解盘方法包括用神选取、吉凶格局判断、门宫生克分析、星门神仪综合判断等步骤。解盘时需遵循"先看大局，再看用神，后看细节"的基本顺序。

---

## 二、用神选取

### 2.1 基本用神法则

用神是奇门解盘的核心参照物，选取正确的用神是准确解盘的前提。

**核心原则**：日干为人，时干为事。

| 用神 | 代表 | 说明 |
|------|------|------|
| 日干 | 求测人 | 代表问卦者本人，日干落宫反映求测者状态 |
| 时干 | 所问之事 | 代表所问的事件，时干落宫反映事情的状态 |
| 年命 | 用神根基 | 以出生年天干为年命，落宫反映命主根基 |
| 值符 | 当前运势 | 代表当前整体运势和时空大环境 |
| 值使 | 事体发展 | 代表事情的具体发展方向和过程 |

### 2.2 分类用神

**婚姻感情**：
- 乙奇代表女方，庚代表男方
- 六合为婚姻中介、媒妁
- 休门为家庭、婚姻生活
- 乙庚落宫相生则吉，相克则凶

**事业财运**：
- 开门为工作、事业、官职
- 生门为财运、利润、产业
- 戊为资本、本金
- 值符为上级领导、顶头上司

**健康疾病**：
- 天芮星为疾病星、病神
- 死门为病症、死亡
- 伤门为外伤、手术
- 乙奇为医药、医生
- 日干/年命落宫为病人自身

**考试求学**：
- 天辅星为文昌星、考试运
- 景门为文章、试卷、成绩
- 丁奇为文书、录取通知
- 日干为考生，值符为主考官

**出行交通**：
- 伤门为车辆、交通事故
- 惊门为惊恐、意外
- 开门为出发、通达
- 九天为远行、飞行

**官司诉讼**：
- 值符为原告，天乙为被告
- 惊门为律师、口舌
- 景门为诉状、证据
- 开门为法官、判决

### 2.3 用神落宫解读

| 落宫状态 | 含义 |
|----------|------|
| 旺相 | 用神有力，事易成 |
| 休囚 | 用神无力，事难成 |
| 空亡 | 虚而不实，事有变数 |
| 入墓 | 困顿受制，施展不开 |
| 击刑 | 受伤受损，遭遇挫折 |
| 门迫 | 受外部压力，被迫而行 |
| 合格 | 牵绊纠缠，不能速决 |

## 三、吉格

### 3.1 青龙返首（龙回首）

**格局**：天盘戊加临地盘丙。

**原理**：戊为青龙，丙为火，青龙得火而返首。戊土生丙火，火生土，相生有情。

**含义**：大吉之格，主百事顺遂，出行大吉，求财得利，官运亨通，谋事可成。但戊+丙在墓宫则吉中带凶。

### 3.2 飞鸟跌穴（鸟跌穴）

**格局**：天盘丙加临地盘戊。

**原理**：丙为朱雀（飞鸟），戊为穴，朱雀入穴，有归巢之象。

**含义**：大吉之格，主办事顺利，事半功倍，适合求财、签约、谈判，利于文书、消息。

### 3.3 三奇得使

**格局**：三奇（乙、丙、丁）加临值使门所在宫位。

**原理**：三奇为吉神，值使为事体，吉神临事体，自然吉上加吉。

**含义**：大吉之格，主所求之事有贵人相助，百事亨通。但需注意三奇得使后不能入墓、受制，否则吉力大减。

**分类**：
- 乙奇得使：利于婚姻、文书、出行
- 丙奇得使：利于求财、升迁、武职
- 丁奇得使：利于考试、诉讼、谋划

### 3.4 玉女守门

**格局**：天盘丁奇加临值使门所在宫位。

**原理**：丁为玉女，值使为门，玉女守门有守护之美。

**含义**：大吉之格，主利于婚姻喜事，宴会娱乐，暗中相助，阴私之事顺利。但丁+癸（朱雀投江）例外。

### 3.5 三奇贵人升殿

**格局**：
- 乙奇落震宫（乙卯）为日出扶桑，大吉
- 丙奇落离宫（丙午）为月照端门，大吉
- 丁奇落兑宫（丁酉）为星见西方，大吉

**含义**：三奇各归本宫，贵人得位，主百事顺遂，逢凶化吉。

### 3.6 奇游禄位

**格局**：三奇落临官禄位之宫。

**分类**：
- 乙奇到震宫（乙禄在卯）
- 丙奇到巳宫（丙禄在巳）
- 丁奇到午宫（丁禄在午）

**含义**：吉格，主事业顺利，财运亨通，宜求官进取。

### 3.7 天辅时

**格局**：甲子旬中，甲戌旬中等，六甲值符星落旺相之宫，且不逢凶星凶门。

**含义**：天时吉利，主天时协助，万事可成。

### 3.8 其他吉格

| 格局 | 组合 | 含义 |
|------|------|------|
| 天遁 | 生门+丙奇+丁奇 | 百事生旺，利于求财 |
| 地遁 | 开门+乙奇+己 | 宜安营扎寨，设伏 |
| 人遁 | 休门+丁奇+太阴 | 利于密谋，和谈 |
| 风遁 | 乙奇+三吉门+巽宫 | 利于出行，顺风 |
| 云遁 | 乙奇+辛+三吉门 | 利于求雨，隐蔽 |
| 龙遁 | 乙奇+三吉门+坎宫 | 利于水战，祈雨 |
| 虎遁 | 乙奇+辛+生门+艮宫 | 宜招安，攻战 |
| 神遁 | 丙奇+九天+生门 | 宜祭祀，祈祷 |
| 鬼遁 | 丁奇+九地+杜门 | 宜偷袭，埋伏 |

## 四、凶格

### 4.1 太白入荧（白入荧）

**格局**：天盘庚加临地盘丙。

**原理**：庚为太白金星（白虎），丙为荧惑星（火星），太白金星闯入荧惑星领地，为客侵主。

**含义**：凶格，主盗贼必来，外人侵犯，客欺主。求财不利，外出防贼，家有盗患。

### 4.2 荧入太白（荧入白）

**格局**：天盘丙加临地盘庚。

**原理**：丙火（荧惑）入庚金（太白），火克金，火入金乡。

**含义**：凶格，主盗贼离去，内部矛盾，但火入金地终被耗灭，主事有反复，终归不利。

### 4.3 白虎猖狂

**格局**：天盘辛加临地盘乙。

**原理**：辛为白虎，乙为青龙，青龙与白虎相争，白虎占上风，猖狂无制。

**含义**：大凶之格，主出行有灾，婚姻破败，家中不和，有血光之灾。宜静不宜动，出行多凶险。

### 4.4 朱雀投江

**格局**：天盘丁加临地盘癸。

**原理**：丁为朱雀，癸为水（江河），朱雀投入江中，有沉没之象。

**含义**：大凶之格，主文书失散，音信全无，官司不利，口舌是非，有沉溺之灾。考试文书类事大凶。

### 4.5 螣蛇夭矫

**格局**：天盘癸加临地盘丁。

**原理**：癸为螣蛇，丁为火，螣蛇遇火而夭矫（受惊扭曲）。

**含义**：凶格，主虚惊怪异，口舌是非，阴谋诡计，事情反复难成，防小人暗算。

### 4.6 大格

**格局**：天盘庚加临地盘癸。

**原理**：庚为阻隔，癸为闭藏，阻隔加闭藏，事难通。

**含义**：大凶之格，主百事不利，出行阻隔，官司难胜，求财不得，婚姻不成。大凶之格局。

### 4.7 小格

**格局**：天盘壬加临地盘庚，或庚加壬。

**含义**：凶格，主出行有阻，变动迁移不利，防人暗算，但比大格稍轻。

### 4.8 刑格

**格局**：天盘庚加临地盘己。

**原理**：己为刑，庚为阻隔，刑上加阻隔。

**含义**：凶格，主官司牢狱，刑伤之灾，受制于人，办事受阻。

### 4.9 悖格

**格局**：
- 天盘丙加临地盘甲子戊（或甲戌己等六甲），为天乙伏宫
- 天盘丙加临时干，为飞宫悖格
- 丙加临年命、月命、日命、时命，为悖格

**含义**：主犯上作乱，悖逆之事，有口舌是非，官非词讼。

### 4.10 五不遇时

**格局**：时干克日干，且时干与日干之间隔五位。

**判断方法**：
- 时干克日干，且时干序号 = 日干序号 + 5（或 -5，即相隔五位）

**具体对应**：
- 甲日庚午时、乙日辛巳时、丙日壬辰时
- 丁日癸卯时、戊日甲寅时、己日乙丑时
- 庚日丙子时、辛日丁酉时、壬日戊申时、癸日己未时

**含义**：大凶之时，此时问卦多不吉，诸事不宜。但若逢吉门吉格，可稍减凶性。

### 4.11 其他凶格

| 格局 | 组合 | 含义 |
|------|------|------|
| 伏吟 | 天盘星与地盘星相同 | 事态停滞，不宜行动 |
| 反吟 | 天盘星与地盘星对冲 | 事态反复，半途而废 |
| 六仪击刑 | 六仪落刑宫 | 刑伤之灾，官司凶险 |
| 三奇入墓 | 乙入未、丙入戌、丁入丑 | 吉事不吉，有力难施 |
| 时干入墓 | 时干落墓库之宫 | 办事不成，拖延受阻 |
| 门迫 | 门克宫 | 被迫行事，身不由己 |

## 五、门宫生克

### 5.1 门宫关系总论

八门与所落宫位之间的五行生克关系，是判断吉凶的重要依据之一。

| 关系 | 术语 | 吉凶 | 含义 |
|------|------|------|------|
| 门生宫 | 泄气 | 次吉 | 事能成但费力，付出多回报少 |
| 宫生门 | 得助 | 大吉 | 事易成，得环境助力 |
| 门克宫 | 门迫 | 凶 | 被外部环境逼迫，身不由己 |
| 宫克门 | 受制 | 次凶 | 受环境制约，事难推进 |
| 门宫比和 | 和谐 | 吉 | 门与宫相得益彰，和谐顺利 |

### 5.2 三吉门与三凶门

**三吉门**：开门、休门、生门。此三门落宫得生助为大吉，吉门被克则吉力减半，吉门克宫则吉中带凶。

**三凶门**：死门、惊门、伤门。此三门落宫受克则凶上加凶，凶门生宫则凶力稍减，凶门被宫生则凶中藏吉。

**平门**：杜门、景门。此二门随格局变化，吉格则吉，凶格则凶。

**生门（土）**：

**伤门（木）**：

## 六、综合解盘方法

### 6.1 解盘顺序

**第一步：看大局**
- 阴阳遁判断大环境
- 伏吟/反吟判断事态动静
- 五不遇时判断时空基础

**第二步：看用神**
- 日干落宫看求测者状态
- 时干落宫看所问之事
- 年命落宫看根基运势

**第三步：看吉凶格**
- 检查日干、时干、用神宫是否有吉格或凶格
- 吉格加持则事易成，凶格临身则事难为

**第四步：看门宫生克**
- 用神宫八门与宫位的生克关系
- 三吉门得助为吉，三凶门受制可减凶

**第五步：看星神配合**
- 九星吉凶与用神的配合
- 八神对用神的影响

**第六步：看宫与宫的关系**
- 日干宫与时干宫的五行生克
- 各用神宫之间的生克关系

**第七步：综合判断**
- 综合以上因素，权衡吉凶，得出最终判断

### 6.2 吉凶等级判断

| 等级 | 条件 |
|------|------|
| 大吉 | 日干落宫旺相 + 三吉门得助 + 三奇吉格 + 值符/九天/太阴 |
| 吉 | 日干落宫旺相 + 吉门 + 无凶格 |
| 平 | 日干落宫平和 + 吉凶参半 |
| 凶 | 日干落宫休囚 + 凶门 + 凶格 |
| 大凶 | 日干入墓/空亡 + 凶门宫迫 + 大凶格 + 白虎/玄武 |

### 6.3 应期判断

**主要方法**：
- 以用神落宫的地支数为应期（如落坎宫，应期可能为子日或一数）
- 以用神落宫的五行为应期（如落离宫火，应期可能为午日）
- 以马星（寅申巳亥）为动应之期
- 填空之时（空亡宫填实之时）
- 冲墓之时（入墓之宫被冲之时）

## 七、解盘注意事项

1. **忌单一指标判断**：不可仅凭一个格局或一个门宫关系下结论，需综合考量。

2. **吉中有凶，凶中有吉**：大吉格局中若有空亡、入墓，则吉力大减；大凶格局中若有三奇得使、吉门得助，则可减轻凶性。

3. **时空一体**：同一时辰不同方位，吉凶可能截然不同。解盘时需结合方位判断。

4. **一事一断**：同一时刻问不同事项，用神取法不同，结论也可能不同。

5. **主客之分**：先动者为主，后动者为客。日干为主，时干为客。主客关系不同，判断侧重也不同。

6. **急则从神**：突发紧急事项，以八神为主判断。

7. **缓则从门**：长期慢性事项，以八门为主判断。

8. **动静结合**：静态看天盘地盘，动态看人盘神盘。

---

*注：解盘之法，流派众多，以上为通用之法。具体应用中应结合实际情况灵活变通，不可生搬硬套。*
