# 小六壬进阶分析

## 一、六宫组合判断

在实际占卜中，月、日、时三轮分别落在不同的宫位，形成宫位组合。通过分析宫位之间的关系，可以得出更丰富、更细致的判断。

### 组合分析原则

1. **最终落宫为主**：时辰落宫是最终结果，权重最高
2. **月宫为背景**：月宫代表大环境、外在条件
3. **日宫为过程**：日宫代表事物发展的中间过程
4. **时辰为结果**：时辰落宫代表最终走向和结论

### 常见组合断法

#### 大安 + 速喜（吉 + 吉）

- **含义**：好事成双，稳中有快
- **解读**：基础稳固的情况下，将迎来快速的喜事或进展
- **典型场景**：长期积累的事业即将迎来突破，或稳定关系中迎来新的喜悦

#### 大安 + 空亡（吉 + 凶）

- **含义**：先安后空，虎头蛇尾
- **解读**：开始看似顺利，但最终可能落空，需警惕后期变化
- **典型场景**：项目前期进展顺利，但后期可能遇到不可控因素导致失败

#### 留连 + 速喜（凶 + 吉）

- **含义**：拨云见日，柳暗花明
- **解读**：虽然当前处于纠缠不清的状态，但很快会迎来转机
- **典型场景**：长期困扰的问题即将有突破，等待的消息即将到来

#### 留连 + 赤口（凶 + 凶）

- **含义**：雪上加霜，事态恶化
- **解读**：本来就处于不利局面，还可能遇到口舌是非或冲突
- **典型场景**：项目拖延的同时又遇到人事纠纷，需格外谨慎

#### 速喜 + 小吉（吉 + 吉）

- **含义**：喜上加喜，万事亨通
- **解读**：六宫中最好的组合之一，诸事顺利，心想事成
- **典型场景**：事业感情双丰收，是最有利的组合

#### 赤口 + 空亡（凶 + 凶）

- **含义**：大凶之兆，百事不宜
- **解读**：六宫中最不利的组合，事态严重，需谨慎应对
- **典型场景**：重大决策建议推迟，投资和出行需格外小心

#### 小吉 + 赤口（吉 + 凶）

- **含义**：乐极生悲，好事多磨
- **解读**：虽然大趋势向好，但过程中可能遇到口舌是非
- **典型场景**：合作总体顺利，但需要注意合同细节和沟通方式

#### 空亡 + 大安（凶 + 吉）

- **含义**：否极泰来，转危为安
- **解读**：虽然当前处于不利局面，但最终会归于安稳
- **典型场景**：危机即将过去，坚持就是胜利

## 二、落宫旺衰

### 旺衰判断原则

每个宫位在不同的时间条件下会有旺衰变化，影响其吉凶程度的强弱。

#### 五行旺衰基础

| 宫名 | 五行 | 旺于 | 相于 | 休于 | 囚于 | 死于 |
|------|------|------|------|------|------|------|
| 大安 | 木 | 春 | 冬 | 夏 | 四季末 | 秋 |
| 留连 | 水 | 冬 | 秋 | 春 | 夏 | 四季末 |
| 速喜 | 火 | 夏 | 春 | 四季末 | 秋 | 冬 |
| 赤口 | 金 | 秋 | 四季末 | 冬 | 春 | 夏 |
| 小吉 | 木 | 春 | 冬 | 夏 | 四季末 | 秋 |
| 空亡 | 土 | 四季末 | 夏 | 秋 | 冬 | 春 |

### 旺衰的具体影响

#### 吉宫旺盛时

- 大安旺于春：春季落大安，吉上加吉，安稳之象最强
- 速喜旺于夏：夏季落速喜，喜事来得又快又好
- 小吉旺于春：春季落小吉，和谐顺遂之象最为显著

#### 吉宫衰弱时

- 大安死于秋：秋季落大安，安稳之象减弱，但仍属吉
- 速喜死于冬：冬季落速喜，喜事来得慢，但仍有喜
- 小吉死于秋：秋季落小吉，吉利程度打折扣

#### 凶宫旺盛时

- 赤口旺于秋：秋季落赤口，口舌是非尤为严重
- 留连旺于冬：冬季落留连，拖延之象更甚
- 空亡旺于四季末：季末落空亡，空亡之凶性最强

#### 凶宫衰弱时

- 赤口死于夏：夏季落赤口，口舌之凶有所减弱
- 留连死于四季末：季末落留连，拖延之象减弱
- 空亡死于春：春季落空亡，凶性相对较弱

### 旺衰综合判断

| 吉宫 + 旺 = 大吉 | 吉宫 + 衰 = 小吉（减半） |
| 凶宫 + 旺 = 大凶 | 凶宫 + 衰 = 小凶（减半） |

## 四、特殊格局

### 1. 三合局

当三个宫位形成五行相生的关系时，称为"三合格局"。

- **大安（木）→ 速喜（火）→ 空亡（土）**：木生火，火生土，形成连续相生，凡事有层层推进之象
- **留连（水）→ 大安（木）→ 速喜（火）**：水生木，木生火，困境中孕育转机，最终迎来喜事

### 2. 对冲格局

- **大安（东） vs 赤口（西）**：东西对冲，安稳与冲突对抗，最终落宫决定胜负
- **留连（北） vs 速喜（南）**：南北对冲，拖延与速决相抗

### 3. 反复格局

当月份和日期的落宫相同，形成"反复"格局：
- 若为吉宫：好事成双，吉上加吉
- 若为凶宫：凶事加重，需加倍小心

### 4. 全吉格局

月、日、时三轮均落吉宫（大安、速喜、小吉），为"全吉"，极为罕见，凡事大吉大利。

### 5. 全凶格局

月、日、时三轮均落凶宫（留连、赤口、空亡），为"全凶"，需格外谨慎，建议另择时日。

### 6. 转运格局

月宫凶、日宫凶、时宫吉：先凶后吉，否极泰来
月宫吉、日宫吉、时宫凶：先吉后凶，功亏一篑

## 六、特殊情况处理

### 闰月处理

遇到闰月时，按正常月份推算，闰月与本月相同。

### 子时特殊性

子时（23:00-01:00）跨越两天，推算时需注意：
- 23:00-00:00 属于当天
- 00:00-01:00 属于第二天

若不确定，建议按子时推算即可，误差通常在可接受范围内。

### 同一问题多次占卜

小六壬不适合在短时间内对同一问题反复占卜。一般原则：
- 同一问题短期内不宜占卜超过 3 次
- 若结果不确定，建议等待至少一个时辰后再占
- 多次结果不一致时，以第一次为准

### 禁忌事项

1. 心不诚不占——心存戏谑或测试心态时不宜占卜
2. 事不关己不占——与己无关的事情不宜占卜
3. 大凶之日不占——农历初一、十五谨慎占卜（部分流派观点）
4. 酒后不占——酒后神志不清，不宜占卜
5. 子时不占——子时阴气重，部分流派建议避开（但多数流派不忌）
