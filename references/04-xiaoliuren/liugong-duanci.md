小六壬六宫各有固定的五行属性、吉凶判词和断辞内容。每一宫代表一种特定的状态和趋势，是占卜判断的核心依据。

## 一、大安——青龙木

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 食指根部下节 |
| 五行 | 木（属阳木） |
| 六神 | 青龙 |
| 吉凶 | 大吉 |
| 方位 | 东方 |
| 数理 | 1、5、7 |
| 主色 | 青色、绿色 |
| 主事 | 安稳、平和、顺利 |

### 断辞原文

> 大安事事昌，求谋在东方，失物去不远，宅舍保安康。
> 行人身未动，病者主无妨，将军回田野，仔细更推详。

### 断辞释义

- **事事昌**：诸事顺利，所求之事有好的开端
- **求谋在东方**：谋事求财宜往东方，或在东方方位有利
- **失物去不远**：丢失的物品不会走远，容易找回
- **宅舍保安康**：家庭平安健康，住宅安宁
- **行人身未动**：出行之人尚未动身，或即将出发
- **病者主无妨**：病人没有大碍，病情稳定或好转
- **将军回田野**：在外之人将回归故里，有归家之象

### 现代解读

大安是六宫中最吉利的宫位之一，象征一切处于安稳、有序的状态。在占卜中落大安，通常表示：
- 所求之事有良好的基础，可以按计划进行
- 人际关系和谐，没有大的波折
- 财运平稳，适合稳扎稳打的投资策略
- 身体健康，没有大的隐患

### 适用场景

- **事业**：工作稳定，适合长期规划，不宜冒进
- **感情**：关系稳定，适合培养感情基础
- **健康**：身体状况良好，保持即可
- **出行**：出行顺利，但未必需要立即出发
- **失物**：物品未远，可在附近寻找，东方可能性大
- **考试**：准备充分，成绩稳定

## 二、留连——玄武水

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 食指根部上节 |
| 五行 | 水（属阴水） |
| 六神 | 玄武 |
| 吉凶 | 凶 |
| 方位 | 北方 |
| 数理 | 2、8、10 |
| 主色 | 黑色、暗色 |
| 主事 | 拖延、纠缠、不明 |

### 断辞原文

> 留连事难成，求谋日未明，官事只宜缓，去者未回程。
> 失物南方见，急讨方称心，更须防口舌，人口且平平。

### 断辞释义

- **事难成**：事情难以顺利推进，多有阻碍
- **求谋日未明**：谋划之事前景不明朗，时机未到
- **官事只宜缓**：涉及官司纠纷宜缓不宜急
- **去者未回程**：离开的人还没有归来的迹象
- **失物南方见**：丢失物品可能在南方找到
- **急讨方称心**：需要主动积极寻找才能如愿
- **防口舌**：谨防口舌是非，少说为妙

### 现代解读

留连代表事情处于胶着、未明朗的状态。落留连时，往往意味着：
- 事情进展缓慢，需要耐心等待
- 信息不透明，难以做出准确判断
- 人际关系可能有暗流涌动，需谨慎处理
- 决策不宜仓促，等局势明朗后再行动

### 适用场景

- **事业**：进展受阻，需等待时机，不宜强行推进
- **感情**：关系暧昧不清，或处于冷战、犹豫期
- **健康**：病情迁延不愈，需持续关注
- **出行**：出行受阻或有变数，建议暂缓
- **失物**：寻找困难，但并非完全没有希望，需主动寻找
- **考试**：准备不足，成绩可能不理想

## 三、速喜——朱雀火

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 食指尖 |
| 五行 | 火（属阳火） |
| 六神 | 朱雀 |
| 吉凶 | 中吉 |
| 方位 | 南方 |
| 数理 | 3、6、9 |
| 主色 | 红色、赤色 |
| 主事 | 快速、喜讯、火热 |

### 断辞原文

> 速喜喜来临，求财向南行，失物申午未，逢人路上寻。
> 官事有福德，病者无祸侵，田宅六畜吉，行人有信音。

### 断辞释义

- **喜来临**：喜事将临，好消息即将到来
- **求财向南行**：求财宜往南方，或在南方方位有利
- **失物申午未**：失物可能在申时、午时、未时找回
- **逢人路上寻**：在路上可能遇到帮助或好消息
- **官事有福德**：诉讼等事务有好的转机
- **病者无祸侵**：病人不会有大碍
- **行人有信音**：出行之人将有消息传来

### 现代解读

速喜代表喜事来得快、好消息在路上的状态。落速喜时，通常意味着：
- 所求之事将有快速的正面进展
- 财运有上升趋势，适合短期投资或快速行动
- 社交活跃，可能遇到贵人
- 适合把握当下时机，快速行动

### 适用场景

- **事业**：有快速进展，适合抓住机遇，积极行动
- **感情**：缘分将至，暧昧关系可能快速明朗化
- **健康**：病情好转快，恢复迅速
- **出行**：出行顺利，适合立即出发
- **失物**：有希望快速找回，可向南方寻找
- **考试**：有意外之喜，成绩可能超预期

## 四、赤口——白虎金

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 无名指尖 |
| 五行 | 金（属阳金） |
| 六神 | 白虎 |
| 吉凶 | 大凶 |
| 方位 | 西方 |
| 数理 | 4、7、9 |
| 主色 | 白色 |
| 主事 | 口舌、是非、破败 |

### 断辞原文

> 赤口主口舌，官非切要防，失物急去寻，行人有惊慌。
> 鸡犬多作怪，病者出西方，更须防诅咒，恐怕染瘟癀。

### 断辞释义

- **主口舌**：易有口舌是非、争执纠纷
- **官非切要防**：务必防范官司诉讼等法律问题
- **失物急去寻**：丢失物品需尽快寻找，否则难以找回
- **行人有惊慌**：出行之人可能遇到惊吓或意外
- **鸡犬多作怪**：家中可能有小麻烦、小是非
- **病者出西方**：病人可能与西方方位有关
- **防诅咒**：谨防小人暗算、流言蜚语

### 现代解读

赤口是六宫中凶性最强的宫位之一，主口舌是非和突发性冲突。落赤口时，需特别注意：
- 最近容易与人发生争执，言行需谨慎
- 可能遇到法律纠纷或合同问题
- 财运不佳，可能有破财之象
- 情绪容易激动，需要控制脾气

### 适用场景

- **事业**：易有口舌纠纷，注意职场人际关系，签署文件需谨慎
- **感情**：容易吵架争执，感情出现裂痕，需冷静沟通
- **健康**：注意口腔、咽喉、呼吸系统问题，防意外伤害
- **出行**：出行不利，可能有意外，建议暂缓或加倍小心
- **失物**：找回困难，需尽快行动
- **考试**：状态不佳，容易发挥失常

## 五、小吉——六合木

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 无名指根部上节 |
| 五行 | 木（属阴木） |
| 六神 | 六合 |
| 吉凶 | 大吉 |
| 方位 | 东北 |
| 数理 | 1、5、7 |
| 主色 | 青色、绿色 |
| 主事 | 和合、顺利、喜事 |

### 断辞原文

> 小吉最吉昌，路上好商量，阳人来报喜，失物在坤方。
> 行人立便至，交关真是强，凡事皆和合，病者祷上苍。

### 断辞释义

- **最吉昌**：是六宫中最吉利的宫位之一
- **路上好商量**：出行途中遇事好商量，谈判顺利
- **阳人来报喜**：将有男性（或阳性）的人带来好消息
- **失物在坤方**：丢失物品在西南方（坤方）
- **行人立便至**：出行之人立刻就到
- **交关真是强**：交易、合作等事宜顺利
- **凡事皆和合**：万事和谐，诸事顺遂

### 现代解读

小吉是六宫中吉利的巅峰，代表万事和谐、心想事成的状态。落小吉时：
- 几乎所有事情都会朝着好的方向发展
- 人际关系极佳，合作顺利
- 财运亨通，适合投资和开展新项目
- 有贵人相助，好事连连

### 适用场景

- **事业**：万事顺遂，适合开展新项目、签约合作
- **感情**：感情甜蜜，适合表白、求婚、复合
- **健康**：身体状态良好，康复迅速
- **出行**：出行大吉，一路顺风
- **失物**：容易找回，尤其是在西南方
- **考试**：考试顺利，成绩理想

## 六、空亡——勾陈土

### 基本信息

| 属性 | 内容 |
|------|------|
| 宫位 | 中指尖 |
| 五行 | 土（属阴土） |
| 六神 | 勾陈 |
| 吉凶 | 大凶 |
| 方位 | 中央 |
| 数理 | 3、6、9 |
| 主色 | 黄色 |
| 主事 | 落空、虚妄、不实 |

### 断辞原文

> 空亡事不祥，阴人多乖张，求财无利益，行人有灾殃。
> 失物寻不见，官事有刑伤，病人逢暗鬼，禳解保安康。

### 断辞释义

- **事不祥**：诸事不吉，所做之事多有不顺
- **阴人多乖张**：可能有小人作祟，或女性方面带来麻烦
- **求财无利益**：谋财不利，可能亏损
- **行人有灾殃**：出行之人可能遇到灾祸
- **失物寻不见**：丢失物品难以找回
- **官事有刑伤**：诉讼官司可能带来伤害
- **病人逢暗鬼**：病人病情复杂，可能有隐情

### 现代解读

空亡是六宫中凶性最盛者，代表事情落空、虚妄不实的状态。落空亡时：
- 计划可能落空，需要重新规划
- 投资需格外谨慎，容易亏损
- 人际关系可能有小人作祟
- 凡事不宜轻信，需多方验证

### 适用场景

- **事业**：计划可能落空，不宜做重大决策，以守为主
- **感情**：感情不实，可能遇到欺骗或失望
- **健康**：病情可能有隐情，需详细检查
- **出行**：出行不利，建议取消或推迟
- **失物**：基本难以找回
- **考试**：成绩可能不理想，需加倍努力
