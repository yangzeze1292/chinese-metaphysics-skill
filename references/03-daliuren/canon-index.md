# 经典文献索引

## 概述

大六壬作为中国传统三式（太乙、奇门、六壬）之一，历代典籍丰富。本文收录四部核心经典文献，详述其作者、成书年代、内容结构、学术价值及主要版本，供研习者参考查阅。

---

## 一、《六壬大全》

### 基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 《六壬大全》 |
| 作者 | 郭载騋（字御青），明末清初人 |
| 成书年代 | 约清康熙年间（约17世纪末） |
| 卷数 | 十二卷（亦有版本作十四卷） |
| 收录 | 《四库全书》子部术数类 |

### 内容结构

《六壬大全》是六壬学集大成之作，系统整理了明代以前六壬典籍的核心内容。全书结构如下：

**卷一至卷三：基础理论**
- 卷一：六壬名义、干支、五行、天干寄宫、地支方位等基础概念。
- 卷二：月将、天盘布法、地盘十二宫、分野。
- 卷三：四课起法、三传发传法（九宗门详述）。

**卷四至卷六：核心技法**
- 卷四：十二天将详解，贵人起法，顺逆布法。
- 卷五：六十四课体分类详解，各课体之格局、含义、吉凶。
- 卷六：神煞系统，包括岁煞、月煞、日煞、时煞等。

**卷七至卷九：占断应用**
- 卷七：占断总论，五行生克、旺相休囚、遁干旬空。
- 卷八：分类占断——天时、地理、人事、婚姻、官禄。
- 卷九：分类占断——疾病、词讼、出行、逃亡、盗贼。

**卷十至卷十二：附录**
- 卷十：杂占、杂论、补遗。
- 卷十一：历代六壬要诀辑录。
- 卷十二：六壬歌诀、赋文汇编。

### 学术价值

1. **集大成者**：汇集明代以前六壬典籍精华，去芜存菁，体系完整。
2. **体系化**：首次将六壬学理系统化、条理化，形成完整的教学体系。
3. **权威性**：被收入《四库全书》，为后世六壬研习者必读之书。
4. **实用性**：既有理论阐述，又有大量实例，理论与实用并重。

### 主要版本

- 《四库全书》本（文渊阁）
- 清康熙刻本
- 清光绪刻本
- 现代整理排印本（多家出版社出版）

### 研读建议

- 初学者宜先读卷一至卷三，掌握基础理论。
- 进阶研读卷四至卷六，掌握核心技法。
- 应用研读卷七至卷九，学习分类占断。
- 全书需反复研读，方能领悟六壬精髓。

## 二、《大六壬心镜》

### 基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 《大六壬心镜》 |
| 作者 | 徐道符（号清溪道人），唐代人 |
| 成书年代 | 唐代（约8-9世纪） |
| 卷数 | 八卷（现存七卷） |
| 收录 | 民间流传，多种抄本 |

### 内容结构

《大六壬心镜》是现存最早的六壬专著之一，流传甚广。全书以歌诀形式阐述六壬要义，简洁明了。现存内容结构如下：

**卷一：基础篇**
- 六壬源流
- 干支五行
- 月将十二神
- 天盘地盘

**卷二：起课篇**
- 四课起法
- 九宗门发传
- 三传推演

**卷三：天将篇**
- 十二天将赋
- 贵人起法
- 天将吉凶

**卷四：课体篇**
- 六十四课体
- 课体吉凶

**卷五：神煞篇**
- 各类神煞
- 神煞应用

**卷六：占断篇**
- 分类占断
- 占断要诀

**卷七：杂占篇**
- 杂占辑要
- 秘诀汇编

**卷八：附录篇**（已佚）
- 据传为古诀秘传，今已不存。

### 学术价值

1. **年代最早**：现存最早的六壬专著之一，保留了大量唐代六壬古法。
2. **歌诀形式**：以歌诀传道，朗朗上口，便于记诵和传承。
3. **古法遗存**：保留了唐代六壬的原始面貌，与后世六壬有差异。
4. **承前启后**：上承汉魏六朝六壬之学，下启宋元明清六壬之发展。

### 主要版本

- 明抄本（多种）
- 清抄本（多种）
- 现代整理本（《心镜》校注本）

### 研读建议

- 注意唐代六壬与明清六壬的差异，不可混淆。
- 歌诀虽然是核心，但需结合注释理解其深意。
- 与《六壬大全》对照阅读，可发现六壬学的演变脉络。

## 三、《大六壬指南》

### 基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 《大六壬指南》 |
| 作者 | 陈公献（字子龙），明末清初人 |
| 成书年代 | 清顺治年间（约17世纪中） |
| 卷数 | 五卷 |
| 收录 | 民间流传，多种刻本 |

### 内容结构

《大六壬指南》是明清之际六壬占断的实战经典，重实例、重应用，与《六壬大全》的理论体系相辅相成。全书结构如下：

**卷一：指掌篇**
- 六壬纲要
- 起课总诀
- 九宗门指掌
- 三传推演法

**卷二：会纂篇**
- 十二天将会纂
- 六十四课体会纂
- 神煞会纂

**卷三：占断篇**
- 天时占
- 地理占（风水、宅墓）
- 人事占（婚姻、子嗣、官禄、财帛）
- 疾病占
- 词讼占
- 出行占
- 盗贼占
- 逃亡占

**卷四：实例篇**
- 历代占验实例汇编
- 陈公献自占实例
- 古今名课选录

**卷五：杂论篇**
- 六壬杂论
- 占断心法
- 秘诀传承

### 学术价值

1. **实战性强**：重实例、重应用，是六壬占断的实战指南。
2. **明清理路**：代表明清六壬的发展方向和断课风格。
3. **系统分类**：分类占断体系完备，条理清晰。
4. **实例丰富**：收录大量占验实例，可学习断课思路。

### 主要版本

- 清顺治刻本
- 清康熙刻本
- 清光绪刻本
- 现代整理排印本

### 研读建议

- 已掌握基础理论后再读此书，方能领会其精妙。
- 重点研读实例篇，揣摩古人断课思路。
- 与《六壬大全》互为补充，理论＋实战。

## 四、《壬归》

### 基本信息

| 项目 | 内容 |
|------|------|
| 书名 | 《壬归》 |
| 作者 | 佚名（一说为尹锋或张官德），清代人 |
| 成书年代 | 清代中后期（约18-19世纪） |
| 卷数 | 三卷（亦有版本作四卷或五卷） |
| 收录 | 民间流传，多种抄本及刻本 |

### 内容结构

《壬归》之名取"万法归一"之意，重在总结六壬要义，化繁为简。全书以简明扼要著称，条理分明，是六壬研习者的入门至进阶之书。内容结构如下：

**上卷：起课法**
- 六壬源流总论
- 地盘、天盘、四课、三传
- 九宗门发传
- 伏吟、反吟起法
- 八专日、别责法详述

**中卷：断课法**
- 十二天将断法
- 六十四课体断法
- 神煞断法
- 遁干旬空断法
- 分类占断要诀

**下卷：实战篇**
- 占断实案
- 古今名课辑录
- 断课总诀
- 六壬杂诀

### 学术价值

1. **简明扼要**：化繁为简，将复杂的大六壬学理归纳为简明体系。
2. **入门佳作**：是六壬初学者的最佳入门读物之一。
3. **体系完整**：虽篇幅不大，但体系完整，涵盖起课、断课、实战。
4. **万法归一**：重在总结规律，提炼核心要义。

### 主要版本

- 清刻本（多种）
- 清抄本（多种）
- 民国石印本
- 现代整理排印本

### 研读建议

- 适合初学者入门，先读此书建立六壬整体框架。
- 再读《六壬大全》深入理论，读《指南》学习实战。
- 三书配合阅读，可收事半功倍之效。

## 四部经典关系总览

### 阅读顺序建议

```
《壬归》        → 入门，建立框架（简明）
    ↓
《六壬大全》    → 深入，掌握理论（系统）
    ↓
《大六壬指南》  → 实战，学习断课（应用）
    ↓
《大六壬心镜》  → 溯源，了解古法（研究）
```

### 四部经典对比

| 对比维度 | 六壬大全 | 大六壬心镜 | 大六壬指南 | 壬归 |
|----------|----------|------------|------------|------|
| 年代 | 清初 | 唐代 | 清初 | 清中后期 |
| 侧重 | 理论体系 | 古法歌诀 | 实战占断 | 简明总结 |
| 篇幅 | 大（12卷） | 中（8卷） | 中（5卷） | 小（3卷） |
| 难度 | 中高 | 高（古文） | 中 | 低 |
| 适用 | 系统研习 | 古法研究 | 实战参考 | 入门学习 |
| 风格 | 理论详实 | 歌诀简洁 | 实例丰富 | 简明扼要 |

### 核心内容互补关系

- **起课法**：《六壬大全》最详，《壬归》最简，《心镜》最古。
- **九宗门**：《六壬大全》系统论述，《心镜》古法歌诀，《指南》有实例验证。
- **十二天将**：《六壬大全》论述最全，《指南》有实战断法，《心镜》有古赋。
- **六十四课体**：《六壬大全》为权威出处，《指南》有实例参考。
- **神煞系统**：《六壬大全》最为完整。
- **占断实战**：《指南》最为丰富。

## 研习路径建议

### 第一阶段：入门（1-3个月）

**目标**：掌握六壬基本概念，能独立起课。

**读物**：
1. 《壬归》——通读，建立整体框架。
2. 现代六壬入门教材（如《大六壬精解》）——辅助理解。

**掌握要点**：
- 天干地支、五行生克
- 地盘十二宫、天干寄宫
- 月将、占时、天地盘布法
- 四课起法
- 九宗门基础（至少掌握贼克法、比用法）

### 第二阶段：深入（3-6个月）

**目标**：掌握九宗门全部发传法，理解十二天将和神煞系统。

**读物**：
1. 《六壬大全》卷一至卷六——精读。
2. 《大六壬指南》卷一至卷二——辅助理解。

**掌握要点**：
- 九宗门全部发传法（包括涉害法、遥克法、昴星法等）
- 十二天将的吉凶、属性、所主
- 六十四课体分类
- 神煞系统的运用

### 第三阶段：实战（6-12个月）

**目标**：能独立断课，进行各类事项占断。

**读物**：
1. 《大六壬指南》卷三至卷四——精读实例。
2. 《六壬大全》卷七至卷九——学习分类占断。
3. 《六壬断案》（邵彦和）——揣摩古法断课。

**掌握要点**：
- 综合断课能力
- 分类占断（天时、婚姻、官禄、疾病、出行等）
- 课体与天将、神煞的综合运用
- 实际占验练习

### 第四阶段：研究（长期）

**目标**：深入研究六壬古法，融会贯通。

**读物**：
1. 《大六壬心镜》——研究唐代古法。
2. 其他六壬古代文献——拓宽视野。
3. 现代六壬研究著作——了解当代研究。

**掌握要点**：
- 唐代六壬与明清六壬的差异
- 六壬学理的历史演变
- 不同流派的特点
- 个人断课风格的形成
