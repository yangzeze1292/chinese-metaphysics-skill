# 十二天将详解

## 概述

十二天将，又称"十二天官"、"十二贵神"，是大六壬课式中环绕天盘的重要神煞系统。十二天将各有其固定的五行属性、吉凶属性和所主事类，在断课中与天盘神、地盘宫、三传配合使用，是判断吉凶祸福的核心依据。

十二天将的排列顺序和位置，由**贵人**（天乙贵人）的顺逆来决定。贵人顺布则十二天将顺行，贵人逆布则十二天将逆行。

**十二天将顺次**：贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后

## 一、贵人（天乙贵人）

### 基本信息

| 属性 | 内容 |
|------|------|
| 本家 | 己丑（土） |
| 五行 | 土 |
| 阴阳 | 阴 |
| 吉凶 | **大吉** |
| 分野 | 紫微垣、天乙星 |
| 主宰 | 君主、帝王、天子、贵人、尊长、官禄 |

### 所主事类

- **人事**：官贵、上司、领导、尊者、有地位之人、恩人、靠山。
- **官职**：升迁、官禄、功名、科举、封赏。
- **求谋**：得贵人相助、逢凶化吉、遇难呈祥。
- **婚姻**：佳婿、良缘、贵戚。
- **病讼**：遇良医、官司得理。

### 象意详述

- 贵人为十二天将之首，统领诸神，最为尊贵。
- 贵人得地则吉，失地则减力。
- 贵人与日干相生合，主得贵人扶持；相克冲则主贵人反目或不得力。
- 贵人在不同的地盘宫位，其吉凶程度不同：
  - 在亥、子、丑、寅、卯、辰六宫为**得地**（顺治）。
  - 在巳、午、未、申、酉、戌六宫为**失地**（逆治）。

### 贵人起法

贵人依日干和昼夜而定：
- 甲戊庚日：昼贵丑、夜贵未
- 乙己日：昼贵子、夜贵申
- 丙丁日：昼贵亥、夜贵酉
- 辛日：昼贵午、夜贵寅
- 壬癸日：昼贵巳、夜贵卯

## 二、螣蛇

### 基本信息

| 属性 | 内容 |
|------|------|
| 本家 | 丁巳（火） |
| 五行 | 火 |
| 阴阳 | 阳 |
| 吉凶 | **凶** |
| 分野 | 天市垣 |
| 主宰 | 惊恐、怪异、虚惊、火灾 |

### 所主事类

- **人事**：惊恐怪异之事、虚惊不安、心神不宁、噩梦。
- **灾祸**：火灾、烧烫伤、电击、血光。
- **病讼**：精神疾病、惊风、癫痫、诉讼缠身。
- **性格**：多疑、善变、诡诈、阴险。
- **物象**：蛇、绳索、电线、烟火、文章字迹。

### 象意详述

- 螣蛇为火神，主虚惊怪异，性多猜疑。
- 螣蛇临日干，主其人惊疑不定，心神不安。
- 螣蛇在三传中，主事有反复、中途生变。
- 螣蛇乘火神或临火宫，主火灾、烧烫之厄。
- 螣蛇与朱雀同现，主口舌是非、文书纠纷。

## 三、朱雀

### 基本信息

| 属性 | 内容 |
|------|------|
| 本家 | 丙午（火） |
| 五行 | 火 |
| 阴阳 | 阳 |
| 吉凶 | **凶**（文书之事可吉） |
| 分野 | 太微垣 |
| 主宰 | 文书、口舌、信息、消息 |

### 所主事类

- **文书**：书信、公文、契约、考试、文章、消息、信息。
- **口舌**：是非、争吵、诉讼、诽谤、谣言。
- **考试**：科举、功名、文采、学识。
- **物象**：鸟类、红色物品、印章、书籍、文字。
- **病讼**：口舌生疮、咽喉疾病、诉讼文书。

### 象意详述

- 朱雀为火神，主文书口舌，性急而躁。
- 朱雀临日干，主其人有口才、善言辞，亦主口舌是非。
- 朱雀在初传，主事之初有文书或消息；在末传，主事之结局有口舌。
- 朱雀旺相主文书吉庆，休囚主口舌是非。
- 朱雀与螣蛇同现，主虚惊口舌；与白虎同现，主血光口舌。

## 四、六合

### 基本信息

| 属性 | 内容 |
|------|------|
| 本家 | 乙卯（木） |
| 五行 | 木 |
| 阴阳 | 阴 |
| 吉凶 | **吉** |
| 分野 | 天市垣 |
| 主宰 | 婚姻、和合、媒介、交易 |

### 所主事类

- **婚姻**：媒人、婚事、和合、夫妇。
- **交易**：买卖、商业、中介、经纪人。
- **人事**：和睦、合作、结盟、交友。
- **子孙**：子嗣、后代、儿童。
- **物象**：门户、帘幕、花果、树木、竹木制品。

### 象意详述

- 六合为木神，主和合婚姻，性柔而善。
- 六合临日干，主婚姻和合、交易顺利，或得媒人撮合。
- 六合在三传中，主事有和合、中介、撮合之象。
- 六合与青龙同现，主婚姻喜庆、交易大利。
- 六合与天后同现，主男女私情、婚姻之事。
- 六合逢刑冲克害，主婚姻不成、交易破裂。

### 基本信息

### 所主事类

- **争斗**：打斗、纠纷、冲突、竞争。
- **田土**：土地、房产、农业、不动产。
- **官讼**：牢狱、诉讼、官司、拘禁。
- **人事**：牵连、拖累、纠缠、阻碍。
- **物象**：土地、牢狱、围墙、瓦器、土石。

### 象意详述

- 勾陈为土神，主争斗田土，性固执而滞。
- 勾陈临日干，主其人有田土之争或官司缠身。
- 勾陈在三传中，主事有阻碍、拖延、牵连。
- 勾陈与白虎同现，主争斗血光、牢狱之灾。
- 勾陈与天空同现，主虚诈之讼、不实之事。
- 勾陈旺相主实地、实利，休囚主虚争、空讼。

### 所主事类

- **财帛**：钱财、宝物、珍宝、盈利。
- **喜庆**：婚庆、生子、升迁、高中。
- **官职**：升官、功名、科举高中。
- **文书**：喜信、好消息、捷报。

- 青龙临日干，主其人财运亨通，喜事临门。
- 青龙在三传中，主事有财喜、顺遂如意。
- 青龙与六合同现，主婚姻喜庆、交易得财。
- 青龙与太常同现，主饮食宴乐、财帛丰厚。
- 青龙乘旺相主大财，休囚主小利。

### 基本信息

| 属性 | 内容 |
|------|------|

| 阴阳 | 阳 |
| 吉凶 | **凶** |
| 分野 | 紫微垣 |
| 主宰 | 虚诈、不实、空亡、仆从 |

### 所主事类

- **虚诈**：欺骗、谎言、虚假、不实之事。
- **空亡**：落空、无成、徒劳无功。
- **人事**：奴仆、下人、卑微之人。
- **文书**：虚文、空信、假消息。
- **物象**：空虚之地、垃圾、废物、尘土。

### 象意详述

- 天空为土神，主虚诈不实，性空而伪。
- 天空临日干，主其人所谋不实，或被欺骗。
- 天空在三传中，主事有虚假、不实之处，或最终落空。
- 天空与玄武同现，主盗贼欺骗、虚诈之事。
- 天空与勾陈同现，主虚争空讼。
- 天空为"空亡之神"，吉事逢之减吉，凶事逢之减凶（化无）。

## 十二天将五行生克关系

### 五行分布

- **木**：六合（乙卯）、青龙（甲寅）
- **火**：螣蛇（丁巳）、朱雀（丙午）
- **土**：贵人（己丑）、勾陈（戊辰）、天空（戊戌）、太常（己未）
- **金**：白虎（庚申）、太阴（辛酉）
- **水**：玄武（癸亥）、天后（壬子）

### 天将之间的生克

- 青龙（木）生螣蛇、朱雀（火）——吉生凶，主吉中藏凶，或因喜庆而生口舌。
- 螣蛇、朱雀（火）生贵人、勾陈、天空、太常（土）——凶生吉，主凶中化吉，虚惊过后得贵人扶持。
- 六合、青龙（木）克贵人等（土）——吉克吉，主吉事相争，或因财帛妨官贵。
- 白虎、太阴（金）克六合、青龙（木）——凶克吉，主凶伤吉事，喜庆被破。
- 玄武、天后（水）生六合、青龙（木）——凶生吉，主暗中助力，或阴私之事反成吉庆。

## 天将吉凶配合简诀

- **贵人+青龙**：大吉，官禄财帛双美。
- **贵人+白虎**：显贵中有凶险，贵中藏祸。
- **螣蛇+朱雀**：虚惊口舌，文书纠纷。
- **六合+青龙**：婚姻喜庆，财帛丰盈。
- **勾陈+白虎**：争斗血光，牢狱之灾。
- **天空+玄武**：虚诈欺骗，盗窃落空。
- **太常+青龙**：饮食宴乐，富贵荣华。
- **太阴+天后**：妇女之事，阴私和合。
- **玄武+天后**：男女私情，暗昧之事。
