# 九宗门 —— 发三传九法详解

## 概述

九宗门是大六壬的核心技法，用于在四课布定之后，确定**三传**（初传、中传、末传）。三传代表事物发展的三个阶段：初传为事发之始，中传为事之中途，末传为事之结局。九宗门根据四课中上下神之间的生克关系，分为九种不同的发传方法，依序取用，前法不适用则取后法。

**取用优先级**：贼克法 → 比用法 → 涉害法 → 遥克法 → 昴星法 → 别责法 → 八专法 → 伏吟法 → 反吟法

---

## 一、贼克法

### 适用条件

四课之中，有上神克下神（称"克"）或下神克上神（称"贼"），且仅有一处。

### 核心规则

- **上克下为"克"**：上神克下神，名"元首课"。
- **下克上为"贼"**：下神克上神，名"重审课"。
- **优先取贼**：先取贼（下克上），后取克（上克下）。若同时有贼有克，贼优先。
- **仅有一处**：若四课中仅有一处贼或仅有一处克，即用贼克法。

### 起课步骤

1. **确定初传**：取贼克之神（即发生克制的那个神）为初传。
   - 下克上时，取下神为初传。
   - 上克下时，取上神为初传。
2. **确定中传**：看初传所临地盘（即初传在地盘上的位置，按"月将加时"后的天盘对应），取该地盘之上神为中传。
3. **确定末传**：看中传所临地盘，取该地盘之上神为末传。

### 示例

**例一：下克上（重审课）**

假设甲子日，月将亥加寅时，四课为：
```
    四   三   二   一
    辰   申   午   戌
    申   子   戌   甲
```

- 第一课：甲寄寅宫，寅上神为戌，戌下为甲寅——戌（土）克寅（木），下克上，为贼。
- 取戌为初传。
- 戌临地盘巳（天盘戌在地盘巳上），巳上神为丑，取丑为中传。
- 丑临地盘午（天盘丑在地盘午上），午上神为午，取午为末传。
- 三传：戌 → 丑 → 午

**例二：上克下（元首课）**

假设丙寅日，四课中：
- 第一课：丙寄巳宫，巳上神为子，子上克下（子水克巳火），上克下，为克。
- 取子为初传。
- 子临地盘未，未上神为辰，取辰为中传。
- 辰临地盘丑，丑上神为戌，取戌为末传。
- 三传：子 → 辰 → 戌

## 二、比用法

### 适用条件

四课中有两处或两处以上有贼（下克上）或克（上克下），无法用贼克法唯一确定初传时，用比用法。

### 核心规则

1. **先贼后克**：先取贼（下克上）；若无贼，则取克（上克下）。
2. **比用**：在候选的多个贼/克中，取与日干阴阳相同者。
   - **阳日**（甲、丙、戊、庚、壬）：取阳神（子、寅、辰、午、申、戌）。
   - **阴日**（乙、丁、己、辛、癸）：取阴神（丑、卯、巳、未、酉、亥）。
3. 若比用后仍有多者，则进入涉害法。

### 起课步骤

1. 筛选出所有贼/克之神。
2. 按日干阴阳，取与日干同阴阳者。
3. 以该神为初传，照常法中传、末传。

### 示例

己丑日（阴日），四课中有两处下克上：
- 一处下神为卯（阴），一处下神为酉（阴）。均为阴神，与日干己（阴）同阴阳，则需进一步用涉害法。

癸卯日（阴日），四课中有两处上克下：
- 一处上神为午（阳），一处上神为丑（阴）。日干癸为阴，取丑为初传。

## 三、涉害法

### 适用条件

四课中有多个贼克，且经比用后仍有多个候选（比用相同或无法比用），则用涉害法。

### 核心规则

**涉害**：看被克之神（即受克的地盘之神）在十二宫中所受克害的深浅程度。具体方法为：以该神所临地盘为起点，顺行十二宫，数其受到克制的次数，称为"涉害数"。取涉害数最大者。

### 涉害计算方法

1. 确定初传候选神。
2. 对每个候选神，以其所临地盘为起点，顺时针数十二宫。
3. 在每一宫，检查该宫的地支是否被候选神所克，或候选神是否被该宫地支所克。
4. 统计涉害次数，取次数最多者。
5. 若涉害次数相等，则取先见者（依四课顺序：第一课 → 第二课 → 第三课 → 第四课）。

### 起课步骤

1. 计算每个候选神的涉害数。
2. 取涉害数最大者为初传。
3. 照常法中传、末传。

### 示例

甲辰日，四课中有三处下克上，候选下神分别为寅、卯、辰，且日干甲为阳，均非比用（候选中有阴有阳各多于一个），须用涉害法。

## 四、遥克法

### 适用条件

四课中无贼无克（无上克下亦无下克上），则用遥克法。

### 核心规则

遥克法分两种：

1. **蒿矢（日干遥克）**：日干克四课中某上神。取被日干所克之上神为初传。名"蒿矢课"（如蒿草之箭，力弱而远）。
2. **弹射（遥克日干）**：四课中某上神克日干。取克日干之上神为初传。名"弹射课"（如弹弓射物，力亦弱）。

**优先级**：先取蒿矢（日干克上神），无蒿矢则取弹射（上神克日干）。

### 起课步骤

1. 检查四课各上神，是否有被日干所克者。若有，取之为初传（蒿矢）。
2. 若无，检查四课各上神，是否有克日干者。若有，取之为初传（弹射）。
3. 遥克法中，初传不临地盘（因其为遥克而非直接临克），中传取日干上神，末传取日支上神。
   - 有说：中传取初传所临地盘之上神，末传取中传所临地盘之上神（与普通法同）。

### 示例

壬申日，日干壬，四课中无贼无克。
- 壬水克火，四课上神有午（火），故取午为初传（蒿矢）。
- 或若四课中有未（土）克壬（水），则取未为初传（弹射）。

---

## 五、昴星法

### 适用条件

四课中无贼无克，且无遥克（蒿矢、弹射均无），则用昴星法。

昴星为西方白虎七宿之一，对应地盘酉宫。昴星法取酉宫为关键。

### 核心规则

**阳日昴星**（虎视课）：
- 初传：取地盘酉上神（即酉宫所临天盘之神）。
- 中传：取日干上神。
- 末传：取日支上神。

**阴日昴星**（冬蛇掩目课）：
- 初传：取日支上神（即第四课上神）。
- 中传：取地盘酉上神（即酉宫所临天盘之神）。
- 末传：取日干上神。

**记忆口诀**：
- 阳日：酉上神 → 干上神 → 支上神
- 阴日：支上神 → 酉上神 → 干上神

### 示例

**阳日昴星**：甲寅日，四课无贼克、无遥克。
- 地盘酉上神为某神，取为初传。
- 日干甲上神为中传。
- 日支寅上神为末传。

**阴日昴星**：乙丑日，四课无贼克、无遥克。
- 日支丑上神为初传。
- 地盘酉上神为中传。
- 日干乙上神为末传。

## 六、别责法

### 适用条件

四课中有三课完全相同（即四课实际上只有两课内容不同），且无贼克、无遥克，则用别责法。

别责，意为"别取一责"，即从别处取初传。

### 核心规则

当四课出现三课相同时：
- **初传**：取日干寄宫所合之神。
  - 日干寄宫：甲寄寅、乙寄辰、丙寄巳、丁寄未、戊寄巳、己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。
  - 所合之神：即该寄宫地支的六合神（如寅与亥合、卯与戌合等）。
- **中传**：取日干上神。
- **末传**：取日干上神（中末相同）。

### 起课步骤

1. 确认四课中三课相同。
2. 确定日干寄宫，查其六合之神。
3. 取该六合之神为初传。
4. 中、末传均取日干上神。

### 示例

假设丙辰日，四课中三课相同，无贼克、无遥克。
- 日干丙寄巳宫，巳与申合（巳申合），取申为初传。
- 日干丙上神为中传、末传。
- 三传：申 → 干上神 → 干上神

### 别责变体

又有一说：若四课中有两课相同，且无贼克，亦可用别责法。此时取日干寄宫之合神为初传。

## 七、八专法

### 适用条件

日干支寄在同一宫（即日干寄宫与日支相同），四课中第一课与第三课的上神相同，称为"八专日"。

**八专日**：甲寅、乙卯、丁未、己未、庚申、辛酉、癸丑。共七日。

### 核心规则

**阳日八专**（八专课）：
- 初传：取日干上神，顺数三辰（即从日干上神所在宫顺数三宫，取该宫之神）。
- 中传：取日干上神。
- 末传：取日干上神。

**阴日八专**（帷簿课）：
- 初传：取日干上神，逆数三辰（即从日干上神所在宫逆数三宫，取该宫之神）。
- 中传：取日干上神。
- 末传：取日干上神。

### 起课步骤

1. 确认八专日。
2. 阳日顺数、阴日逆数，从日干上神起数三辰得初传。
3. 中传、末传均取日干上神。

### 示例

**甲寅日（阳日八专）**：
- 日干甲寄寅宫，日支亦为寅，第一课与第三课上神相同。
- 日干上神为某神，顺数三辰，得某神为初传。
- 中传、末传：日干上神。

**辛酉日（阴日八专）**：
- 日干辛寄戌宫，日支酉（此处日干寄戌非酉，需注意）——实际上八专日日干支寄在同一宫，此处的"寄宫"指的是日干寄宫即日支所在宫。
- 日干上神逆数三辰得初传。
- 中传、末传：日干上神。

## 八、伏吟法

### 适用条件

月将加时后，天盘与地盘完全同位（即月将加时刚好加在本宫），天地盘重合，十二宫各神皆在本位不动。此时四课第一课上下神相同，第二课上下神亦同。

### 核心规则

伏吟课分**刚日**和**柔日**两种：

**刚日伏吟**（日干为阳：甲、丙、戊、庚、壬）：
- 自任课。
- 初传：取日干上神（即日干寄宫之上神，因伏吟，即日干寄宫本身）。
- 中传：取日干寄宫之刑神（即日干寄宫地支的刑神）。
- 末传：取中传之刑神。

**柔日伏吟**（日干为阴：乙、丁、己、辛、癸）：
- 自信课。
- 初传：取日支上神（即日支本身）。
- 中传：取日干寄宫之刑神。
- 末传：取中传之刑神。

### 刑神速查

| 地支 | 刑神 | 说明 |
|------|------|------|
| 子 | 卯 | 子刑卯 |
| 卯 | 子 | 卯刑子（无礼之刑） |
| 寅 | 巳 | 寅刑巳 |
| 巳 | 申 | 巳刑申 |
| 申 | 寅 | 申刑寅（无恩之刑） |
| 丑 | 戌 | 丑刑戌 |
| 戌 | 未 | 戌刑未 |
| 未 | 丑 | 未刑丑（恃势之刑） |
| 辰 | 辰 | 自刑 |
| 午 | 午 | 自刑 |
| 酉 | 酉 | 自刑 |
| 亥 | 亥 | 自刑 |

**注意**：若中传为自刑（辰、午、酉、亥），则末传取日支上神。

### 示例

**甲子日（刚日伏吟）**：
- 日干甲寄寅宫，寅上神为寅（伏吟）。初传：寅。
- 寅刑巳，中传：巳。
- 巳刑申，末传：申。
- 三传：寅 → 巳 → 申

**乙丑日（柔日伏吟）**：
- 日支丑上神为丑，初传：丑。
- 日干乙寄辰宫，辰为自刑，辰刑辰。中传取日干刑神，辰为自刑，改取日支上神为末传？——按规则：辰刑辰（自刑），中传为辰，辰为自刑，末传取日支上神丑。
- 三传：丑 → 辰 → 丑

## 九、反吟法

### 适用条件

月将加时后，天盘与地盘完全对冲（即月将加时刚好加在冲位），十二宫天地盘皆相冲。此时四课中第一课上下神相冲，第二课上下神亦相冲。

反吟即"六冲"：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

### 核心规则

**有克反吟**（反吟课中四课有贼克）：
- 先用贼克法取初传，照常法中传、末传。

**无克反吟**（反吟课中四课无贼克）：
- 名"井栏课"（又名"无依课"）。
- 初传：取日支的驿马神。
- 中传：取日支上神。
- 末传：取日干上神。

### 驿马速查

驿马以日支三合局定：
- 申子辰日 → 驿马在寅
- 寅午戌日 → 驿马在申
- 巳酉丑日 → 驿马在亥
- 亥卯未日 → 驿马在巳

### 示例

**甲子日反吟（无克）**：
- 日支子，申子辰三合，驿马在寅。
- 初传：寅。
- 中传：支上神（日支子之上神）。
- 末传：干上神（日干甲之上神）。

**庚午日反吟（有克）**：
- 四课中有贼克，按贼克法取初传。
- 照常法中传、末传。

## 九宗门总诀

```
贼克为先比用次，涉害深浅遥克继。
昴星阳阴各不同，别责三课同一气。
八专顺逆数三辰，伏吟刚柔刑上取。
反吟有克贼克推，无克驿马井栏是。
```
