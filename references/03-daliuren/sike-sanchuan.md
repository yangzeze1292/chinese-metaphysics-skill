# 四课三传排盘法

## 概述

大六壬排盘的核心步骤为：先定地盘，再布天盘（月将加时），次起四课，后发三传。四课代表天地人三才之象，三传代表事物过去、现在、未来之变化。本文详细阐述完整的排盘流程。

## 第二章：天盘布法（月将加时）

### 一、月将的概念

月将，即太阳每月所躔之宫次，为每月中气时太阳所在之宫。大六壬以月将加于占时之上，顺布十二宫，形成天盘。

### 二、十二月将

| 月份 | 月将 | 地支 | 中气 | 说明 |
|------|------|------|------|------|
| 正月 | 登明 | 亥 | 雨水 | 正月将，雨水后用 |
| 二月 | 河魁 | 戌 | 春分 | 二月将，春分后用 |
| 三月 | 从魁 | 酉 | 谷雨 | 三月将，谷雨后用 |
| 四月 | 传送 | 申 | 小满 | 四月将，小满后用 |
| 五月 | 小吉 | 未 | 夏至 | 五月将，夏至后用 |
| 六月 | 胜光 | 午 | 大暑 | 六月将，大暑后用 |
| 七月 | 太乙 | 巳 | 处暑 | 七月将，处暑后用 |
| 八月 | 天罡 | 辰 | 秋分 | 八月将，秋分后用 |
| 九月 | 太冲 | 卯 | 霜降 | 九月将，霜降后用 |
| 十月 | 功曹 | 寅 | 小雪 | 十月将，小雪后用 |

**注意**：月将的起用时间以中气为界，如正月雨水后始用亥将登明，雨水前仍用前月之将。

### 三、月将加时法

"月将加时"是大六壬天盘布法的核心操作：

1. 取当月月将（即对应地支）。
2. 将该月将置于占时（时辰地支）所在的地盘宫位之上。
3. 其余十一将按顺时针方向依次排列。

**操作步骤**：
- 以地盘为固定参照，将月将对应的地支写在地盘"时支"宫的上方。
- 然后从该宫起，顺时针依次写入其余十一个地支，构成天盘。

### 四、月将加时示例

**例**：正月占课（月将亥），占时为寅时。

1. 将月将"亥"置于地盘"寅"宫之上（天盘亥在地盘寅上）。
2. 顺时针排列：
   - 地盘寅 → 天盘亥
   - 地盘卯 → 天盘子
   - 地盘辰 → 天盘丑
   - 地盘巳 → 天盘寅
   - 地盘午 → 天盘卯
   - 地盘未 → 天盘辰
   - 地盘申 → 天盘巳
   - 地盘酉 → 天盘午
   - 地盘戌 → 天盘未
   - 地盘亥 → 天盘申
   - 地盘子 → 天盘酉
   - 地盘丑 → 天盘戌

**天盘图**（以地盘为底，天盘在上）：

```
        天盘：寅  卯  辰  巳
        地盘：巳  午  未  申
      天盘：丑            天盘：午
      地盘：辰            地盘：酉
      天盘：子            天盘：未
      地盘：卯            地盘：戌
        天盘：亥  戌  酉  申
        地盘：寅  丑  子  亥
```

## 第三章：四课起法

### 一、四课的概念

四课是天地盘布定之后，通过日干支与天盘之关系推演出的四组上下神关系，共四课：

- **第一课**：日干寄宫之上神（日干的天盘神）
- **第二课**：第一课上神再临地盘所得之上神
- **第三课**：日支之上神（日支的天盘神）
- **第四课**：第三课上神再临地盘所得之上神

### 二、四课起法步骤

**第一步：确定日干寄宫和日支**

- 日干按寄宫表查出对应地支（如甲日寄寅、乙日寄辰等）。
- 日支即日柱的地支。

**第二步：起第一课**

- 在地盘上找到日干寄宫所在位置。
- 看该位置天盘上是何神（即月将加时后该宫的天盘地支）。
- 该天盘神即为第一课的上神，日干（寄宫）为下神。
- 格式：上神（天盘）/ 下神（地盘日干寄宫）

**第三步：起第二课**

- 以第一课的上神为新的下神（即在地盘上找到该地支的位置）。
- 看该位置天盘上是何神，即为第二课的上神。
- 格式：上神（天盘）/ 下神（第一课上神）

**第四步：起第三课**

- 在地盘上找到日支所在位置。
- 看该位置天盘上是何神，即为第三课的上神。
- 格式：上神（天盘）/ 下神（日支）

**第五步：起第四课**

- 以第三课的上神为新的下神（即在地盘上找到该地支的位置）。
- 看该位置天盘上是何神，即为第四课的上神。
- 格式：上神（天盘）/ 下神（第三课上神）

### 三、四课起法示例

**例**：甲子日，正月（月将亥），寅时占。

**天盘布定**（月将亥加寅时）：
- 地盘寅 → 天盘亥
- 地盘卯 → 天盘子
- 地盘辰 → 天盘丑
- 地盘巳 → 天盘寅
- 地盘午 → 天盘卯
- 地盘未 → 天盘辰
- 地盘申 → 天盘巳
- 地盘酉 → 天盘午
- 地盘戌 → 天盘未
- 地盘亥 → 天盘申
- 地盘子 → 天盘酉
- 地盘丑 → 天盘戌

**起四课**：

1. **第一课**：日干甲寄寅宫，地盘寅上之天盘神为亥（天盘亥在地盘寅上）。
   - 第一课：亥 / 甲（寅）

2. **第二课**：以亥为下神，地盘亥上之天盘神为申（天盘申在地盘亥上）。
   - 第二课：申 / 亥

3. **第三课**：日支子，地盘子之上天盘神为酉（天盘酉在地盘子之上）。
   - 第三课：酉 / 子

4. **第四课**：以酉为下神，地盘酉上之天盘神为午（天盘午在地盘酉上）。
   - 第四课：午 / 酉

**四课排列**：
```
    四    三    二    一
    午    酉    申    亥
    酉    子    亥    甲(寅)
```

### 四、四课简化记法

四课也可用以下方式记忆：

- 第一课：干上神（日干的天盘神）
- 第二课：干上神之上神（干上神的天盘神）
- 第三课：支上神（日支的天盘神）
- 第四课：支上神之上神（支上神的天盘神）

## 第四章：三传发传法（九宗门发传）

### 一、三传的概念

三传代表事物发展的三个阶段：

- **初传（发用）**：事发之始，当前之机。主事之起因、开端、初始状态。
- **中传（移易）**：事之中途，变化之机。主事之发展、变化、过程。
- **末传（归计）**：事之结局，归宿之机。主事之结果、终结、归宿。

### 二、九宗门发传优先级

四课既定，即按九宗门取三传。九宗门有严格的取用顺序：

```
1. 贼克法 → 2. 比用法 → 3. 涉害法 → 4. 遥克法 → 5. 昴星法
→ 6. 别责法 → 7. 八专法 → 8. 伏吟法 → 9. 反吟法
```

前法能用则用前法，前法不能用则顺次取后法。

### 三、各法发传速查

#### 1. 贼克法

**条件**：四课中有一处上克下（克）或下克上（贼），且仅有一处。

**发传**：
- 初传：取贼克之神。
- 中传：初传所临地盘之上神。
- 末传：中传所临地盘之上神。

**优先级**：先取贼（下克上），后取克（上克下）。

#### 2. 比用法

**条件**：四课中有两处或以上贼/克。

**发传**：
- 先取贼，后取克。
- 在候选神中，取与日干同阴阳者（比用）。
- 阳日取阳神，阴日取阴神。
- 初传、中传、末传照常法。

#### 3. 涉害法

**条件**：比用后仍有多个候选。

**发传**：
- 计算每个候选神的涉害数（以其所临地盘为起点，顺行十二宫，数其受克次数）。
- 取涉害最深者为初传。
- 中传、末传照常法。

#### 4. 遥克法

**条件**：四课中无贼无克。

**发传**：
- 蒿矢（日干克上神）：取被日干所克之上神为初传。
- 弹射（上神克日干）：取克日干之上神为初传。
- 优先蒿矢。
- 中传取日干上神，末传取日支上神。
  - 或说：中传取初传所临地盘之上神，末传取中传所临地盘之上神。

#### 5. 昴星法

**条件**：无贼克、无遥克。

**发传**：
- 阳日：初传酉上神 → 中传干上神 → 末传支上神。
- 阴日：初传支上神 → 中传酉上神 → 末传干上神。

#### 6. 别责法

**条件**：四课中三课相同。

**发传**：
- 初传：日干寄宫之六合神。
- 中传、末传：日干上神。

#### 7. 八专法

**条件**：日干寄宫与日支同宫（八专日）。

**发传**：
- 阳日：日干上神顺数三辰为初传。
- 阴日：日干上神逆数三辰为初传。
- 中传、末传：日干上神。

#### 8. 伏吟法

**条件**：月将加时后天地盘同位。

**发传**：
- 刚日（阳干）：初传干上神 → 中传干刑神 → 末传中传刑神。
- 柔日（阴干）：初传支上神 → 中传干刑神 → 末传中传刑神。
- 若中传为自刑，末传取支上神。

#### 9. 反吟法

**条件**：月将加时后天地盘对冲。

**发传**：
- 有克：按贼克法发传。
- 无克（井栏课）：初传驿马神 → 中传支上神 → 末传干上神。

## 第五章：完整排盘示例

### 例：甲子日，正月（雨水后，月将亥），寅时占

#### 第一步：布地盘

地支固定方位：
```
巳  午  未  申
辰        酉
卯        戌
寅  丑  子  亥
```

#### 第二步：布天盘（月将亥加寅时）

将月将亥置于地盘寅宫之上，顺布十二宫：
```
天盘：寅  卯  辰  巳
地盘：巳  午  未  申
天盘：丑        天盘：午
地盘：辰        地盘：酉
天盘：子        天盘：未
地盘：卯        地盘：戌
天盘：亥  戌  酉  申
地盘：寅  丑  子  亥
```

#### 第三步：起四课

1. 干寄宫：甲寄寅
2. 第一课：地盘寅上为天盘亥 → 亥/甲寅
3. 第二课：地盘亥上为天盘申 → 申/亥
4. 第三课：地盘子（日支）上为天盘酉 → 酉/子
5. 第四课：地盘酉上为天盘午 → 午/酉

```
四课：
    四    三    二    一
    午    酉    申    亥
    酉    子    亥    甲(寅)
```

#### 第四步：发三传

检查四课贼克：
- 第一课：亥（水）生甲寅（木），无克。
- 第二课：申（金）克亥（水），上克下，为克。
- 第三课：酉（金）生子（水），无克。
- 第四课：午（火）克酉（金），上克下，为克。

有两处上克下（第二课申克亥、第四课午克酉），需用比用法。
- 日干甲为阳，取阳神。
- 申为阳（申属阳），午为阳（午属阳）。
- 两者均为阳神，与日干同阴阳，比用后仍有多个，需用涉害法。

（此处省略涉害计算细节，假设申涉害数大于午）
- 取申为初传。
- 申临地盘亥（申在地盘亥之上），亥上神为某神，取为中传。
- 中传所临地盘之上神为末传。

#### 第五步：排十二天将

以贵人起法，依日干和昼夜定贵人宫位，顺或逆布十二天将。

## 第七章：排盘注意事项

1. **月将的确定**：必须以中气为界，不可用月份简单对应。
2. **占时的确定**：占时为占卜时刻的时辰地支，非钟表时间，须换算为时辰。
3. **寄宫的准确性**：日干寄宫是四课起课的基础，必须准确无误。
4. **九宗门顺序**：必须严格按照优先级依次判断，不可跳跃。
5. **涉害计算**：涉害法计算较为复杂，需要仔细统计每个候选神的受克次数。
6. **伏吟与反吟**：这两种特殊格局需要首先识别（月将加时后天地盘同位或对冲），再按对应规则发传。
7. **八专日**：共有七日（甲寅、乙卯、丁未、己未、庚申、辛酉、癸丑），需特别注意。
8. **天将的顺逆**：贵人顺布则天将顺行，贵人逆布则天将逆行，不可混淆。
