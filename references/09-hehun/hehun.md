# 八字合婚 · Marriage Compatibility

> 合婚是中国传统命理学中评估两人婚配质量的核心技术，以双方八字为基础，从多个维度进行交叉分析，而非简单的"生肖配不配"。

---

## 一、合婚总纲

### 1.1 合婚的核心理念

合婚不是算命，不是断言"能不能在一起"，而是：
- **评估双方的五行互补性** — 能否互相滋养
- **分析双方的性格兼容度** — 能否和谐相处
- **判断双方的运势同步性** — 能否同甘共苦
- **识别潜在的风险点** — 哪些方面需要注意

《三命通会》云："合婚之法，先看年命纳音，次看日柱干支，再看五行生克，后看神煞冲合。四者俱吉，则为上婚；三者吉，为中婚；二者吉，为下婚。"

### 1.2 合婚的原则

1. **多维度综合，不单一判断**：不能只看生肖，也不能只看日柱
2. **五行互补优先**：五行互补比生肖相合更重要
3. **日柱为婚姻核心**：日柱代表配偶宫，是合婚的重中之重
4. **留有概率边界**：不给"必成/必败/一定离婚"的绝对结论
5. **尊重现实感情**：玄学是参考，不是决定因素

## 二、合婚九维模型

### 维度一：年柱纳音（权重 10%）

**判断方法**：双方年柱纳音五行的生克关系。

| 关系 | 说明 | 评分 |
|------|------|:---:|
| 相生 | A生B 或 B生A | +3 |
| 相同 | 同一种纳音 | +2 |
| 相克 | A克B 或 B克A | -1 |

**纳音五行对照表**：

| 纳音 | 五行 | 纳音 | 五行 | 纳音 | 五行 |
|------|:---:|------|:---:|------|:---:|
| 海中金 | 金 | 炉中火 | 火 | 大林木 | 木 |
| 路旁土 | 土 | 剑锋金 | 金 | 山头火 | 火 |
| 涧下水 | 水 | 城头土 | 土 | 白蜡金 | 金 |
| 杨柳木 | 木 | 泉中水 | 水 | 屋上土 | 土 |
| 霹雳火 | 火 | 松柏木 | 木 | 长流水 | 水 |
| 沙中金 | 金 | 山下火 | 火 | 平地木 | 木 |
| 壁上土 | 土 | 金箔金 | 金 | 覆灯火 | 火 |
| 天河水 | 水 | 大驿土 | 土 | 钗钏金 | 金 |
| 桑柘木 | 木 | 大溪水 | 水 | 沙中土 | 土 |
| 天上火 | 火 | 石榴木 | 木 | 大海水 | 水 |

> **注意**：纳音合婚是传统方法中最粗放的维度，权重最低，不可作为主要依据。

---

### 维度二：生肖关系（权重 10%）

**判断方法**：双方年支（生肖）的合冲刑害关系。

| 关系 | 示例 | 评分 |
|------|------|:---:|
| 六合 | 子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合 | +3 |
| 三合 | 申子辰、寅午戌、亥卯未、巳酉丑 | +2 |
| 无害无冲 | 无特殊关系 | +1 |
| 六冲 | 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲 | -2 |
| 六害 | 子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害 | -2 |
| 三刑 | 寅巳申、丑戌未、子卯 | -3 |

> **重要**：生肖相冲不等于不能结婚。现实中大量"六冲"夫妻白头偕老。生肖只是九维之一，权重仅10%。

---

### 维度三：日柱关系（权重 20%）

**判断方法**：双方日柱天干地支的五行生克和合冲关系。

**日干关系**（代表双方本人的互动）：

| 关系 | 说明 | 评分 |
|------|------|:---:|
| 相生 | A生B 或 B生A → 一方滋养另一方 | +3 |
| 比和 | 同五行 → 志趣相投 | +2 |
| 相克 | A克B 或 B克A → 一方压制另一方 | 0 |

**日支关系**（代表双方配偶宫的互动）：

| 关系 | 说明 | 评分 |
|------|------|:---:|
| 六合 | 配偶宫相合，默契度高 | +3 |
| 三合/半合 | 配偶宫三合，互相吸引 | +2 |
| 比和/无害 | 无冲无害 | +1 |
| 六冲 | 配偶宫相冲，易有矛盾 | -2 |
| 六害 | 配偶宫相害，暗中不和 | -2 |
| 相刑 | 配偶宫相刑，易有伤害 | -3 |

**日柱关系是合婚中权重最高的单一维度**，因为日柱代表婚姻宫。

---

### 维度四：五行互补（权重 15%）

**判断方法**：对比双方八字五行力量分布，看是否互补。

**步骤**：
1. 分别统计双方八字五行力量（天干+地支藏干）
2. 确定双方各自的用神和忌神
3. 判断对方八字是否补自己的用神

| 情况 | 说明 | 评分 |
|------|------|:---:|
| 互相补用神 | 双方各补对方所需 | +5 |
| 一方补另一方 | 只有一方补另一方 | +3 |
| 互不冲突 | 不补也不冲 | +1 |
| 互相冲忌神 | 一方旺另一方忌神 | -2 |
| 严重冲克 | 双方忌神互相冲克 | -4 |

**五行互补是合婚中最有实际意义的维度**，比生肖更重要。

---

### 维度五：十神互动（权重 10%）

**判断方法**：以女方日主为基准，看男方天干在女方命局中的十神角色。

| 十神 | 在婚姻中的含义 | 评分 |
|------|------|:---:|
| 正官 | 女方日主之正官 → 理想夫星，名正言顺 | +3 |
| 正印 | 印星生扶 → 男方呵护女方 | +2 |
| 正财 | 男方日主见女方为正财 → 男方视女方为贤内助 | +2 |
| 食神 | 食神生财 → 男方让女方开心 | +1 |
| 七杀 | 七杀克身 → 男方强势，女方受压 | -1 |
| 伤官 | 伤官见官 → 女方挑剔男方 | -2 |
| 劫财 | 劫财夺财 → 竞争关系 | -2 |

> **注意**：十神互动需要双向分析。以上为以女方为基准，男方为基准需反向推算。

---

### 维度六：大运同步（权重 10%）

**判断方法**：对比双方大运走势，看是否同步。

| 情况 | 评分 |
|------|:---:|
| 双方用神大运同期 → 同甘共苦| +3 |
| 大运走势基本一致 → 节奏同步 | +2 |
| 大运有交错但有重叠 → 有聚有散 | +1 |
| 大运走势相反 → 一方好一方差 | -1 |
| 关键时期大运互相冲克 → 同步困难 | -2 |

---

### 维度七：神煞配合（权重 5%）

**判断方法**：检查双方神煞是否有冲突或互补。

| 神煞 | 吉凶 | 说明 |
|------|:---:|------|
| 桃花相冲 | 凶 | 双方桃花互冲，感情易有第三者 |
| 天乙贵人互见 | 吉 | 双方互为贵人，遇难有救 |
| 羊刃对冲 | 凶 | 脾气冲突，容易争吵 |
| 孤辰寡宿同见 | 凶 | 双方都有孤寡之象，缘分浅 |
| 天月德互见 | 吉 | 双方品德相配，有福气 |

---

### 维度八：用神配合（权重 10%）

**判断方法**：判断双方用神是否一致，以及对方八字是否"补自己的用神"。

| 情况 | 评分 |
|------|:---:|
| 用神一致 + 互相补 → 志同道合，互相促进 | +5 |
| 用神一致但不互补 → 追求相同，但帮不上忙 | +3 |
| 用神不一致但不冲突 → 各走各路，互不干扰 | +1 |
| 用神冲突 → 追求不同，可能互相拖累 | -2 |
| 一方用神 = 另一方忌神 → 严重冲突 | -4 |

---

### 维度九：综合感应（权重 10%）

**判断方法**：整体评估双方八字的"气场"是否和谐。

考虑因素：
- 双方天干地支的合冲关系总数
- 双方八字中共同的五行元素
- 双方的阴阳平衡度
- 双方命局的"温度"（寒暖燥湿）是否互补

**综合评分**：
- 合多冲少，阴阳互补 → +3
- 合冲持平 → +1
- 冲多合少 → -2

## 三、合婚等级判定

### 3.1 加权总分计算

```
总分 = 纳音×10% + 生肖×10% + 日柱×20% + 五行×15% + 十神×10% + 大运×10% + 神煞×5% + 用神×10% + 综合×10%
```

将各维度原始得分（-4到+5）映射到百分制，再加权。

### 3.2 等级标准

| 等级 | 百分制 | 说明 |
|:---:|:---:|------|
| **上等婚** | 80-100 | 五行互补，日柱相合，大运同步，非常理想 |
| **中上婚** | 65-79 | 多数维度协调，少数需注意，较为理想 |
| **中等婚** | 50-64 | 有合有冲，需要双方努力经营 |
| **中下婚** | 35-49 | 冲突较多，需更多包容和理解 |
| **下等婚** | 0-34 | 多个维度严重冲突，需慎重考虑 |

> **重要提示**：现实中绝大多数夫妻属于"中等婚"和"中上婚"。上等婚和下等婚都极少见。合婚分数低不代表不能在一起，只是意味着需要更多的理解、包容和努力。

## 四、合婚工作流

### 标准流程

```
1. 获取双方出生信息
   ├── 男方：农历/公历 年 月 日 时 + 出生地点
   └── 女方：农历/公历 年 月 日 时 + 出生地点

2. 分别排盘
   ├── 男方八字排盘 → 四柱 + 十神 + 格局 + 用神 + 大运
   └── 女方八字排盘 → 四柱 + 十神 + 格局 + 用神 + 大运

3. 九维评估
   ├── 年柱纳音对比
   ├── 生肖合冲刑害
   ├── 日柱干支关系
   ├── 五行力量互补
   ├── 十神角色互动
   ├── 大运走势同步
   ├── 神煞配合分析
   ├── 用神一致/互补
   └── 综合感应评估

4. 加权计算 → 判定等级

5. 输出报告
   ├── 双方八字对照
   ├── 九维评分明细
   ├── 优势与风险点
   ├── 相处建议
   └── 免责声明
```

### 输出格式

合婚报告必须包含以下部分：

1. **双方八字对照表** — 四柱并列，一眼看清
2. **九维评分明细** — 每个维度的得分和理由
3. **综合得分与等级** — 加权总分 + 等级判定
4. **优势分析** — 双方最互补的方面
5. **风险提示** — 需要注意的方面
6. **相处建议** — 具体可操作的建议
7. **免责声明** — 法律和医学提醒

## 五、特殊情况的处理

### 5.1 生肖六冲的化解

生肖六冲（如子午冲、卯酉冲）常被民间认为"不能结婚"，但实际中：
- 六冲夫妻也有很多白头偕老的
- 冲代表"动"，有冲才有激情
- 关键是看其他维度是否互补

**化解思路**：
- 用五行通关：如子午冲（水火冲），用木来通关
- 用合来解冲：如子午冲，用丑来合子、用未来合午
- 实际生活中：培养共同爱好、多沟通、互相包容

### 5.2 日柱相冲

日支相冲（配偶宫相冲）是较严重的信号，但：
- 有合化解则减半（如三合、六合）
- 有印星通关则减半
- 实际生活中：分床睡可缓解、多各自独立空间

### 5.3 一方用神 = 另一方忌神

这是最需要警惕的情况：
- 如果权重高（五行互补+用神配合两个维度都扣分），需要慎重
- 如果仅是某个维度，其他维度满分，总分仍可接受
- 实际生活中：需要更多理解和包容

## 七、禁忌与边界

### 绝对不能说：

- "你们一定会离婚"
- "你们绝对不能在一起"
- "你克夫/克妻"
- "你们八字不合，趁早分手"
- 任何绝对的、决定性的、恐吓性的结论

### 应该说：

- "从五行角度看，你们在XX方面非常互补"
- "在XX方面需要注意，建议多沟通"
- "综合来看，你们的合婚得分是XX，属于XX等级"
- "这是基于传统命理模型的分析，仅供参考"

### 必须声明：

> 合婚分析基于中国传统八字命理模型，属于传统文化范畴。婚姻的幸福与否最终取决于双方的相互理解、包容和共同努力。本分析仅为参考，不构成任何形式的建议或承诺。涉及感情、婚姻等重大人生决策，请结合现实情况理性判断。
