# 经典文献索引

> 命理之学，源远流长。自唐宋以降，代有圣贤立说，著述如林。欲精命理，必读经典。兹录命理五大经典，备述其要，以资研习。

## 一、《渊海子平》

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《渊海子平》 |
| **作者** | 徐大升（南宋）编纂，托名徐子平 |
| **成书年代** | 南宋（约12-13世纪） |
| **卷数** | 五卷（通行本） |
| **地位** | 子平命理学开山之作、八字命理奠基之作 |

### 1.2 内容概要

《渊海子平》是八字命理学的奠基之作，首次系统阐述以日干为中心的"子平法"论命体系。全书以"十神"为纲，以"格局"为目，确立八字推演的基本框架。

**各卷内容**：

- **卷一**：论天干地支、阴阳五行、六十甲子、纳音、节气、排盘基础
- **卷二**：论十神（比肩、劫财、食神、伤官、正财、偏财、正官、七杀、正印、偏印）、论六亲
- **卷三**：论格局（正官格、七杀格、财格、印格、食神格、伤官格等）、论用神
- **卷四**：论大运、论流年、论太岁、论命之吉凶
- **卷五**：赋文歌诀、命例汇编

### 1.3 核心贡献

1. **确立日主中心论**：以日干为"我"，其余七字与日干的关系定十神，此为核心方法
2. **十神体系**：系统建立十神概念，分为比肩、劫财、食神、伤官、正财、偏财、正官、七杀、正印、偏印
3. **格局论命**：以月令取格，建立格局论命框架
4. **大运流年**：创立大运起法，确立顺排逆排规则

### 1.4 经典原文（节选）

**论日主**：
> "予尝观唐书，所载有李虚中者，取人所生年月日时干支生克，论命之贵贱寿夭之说，已详之矣。至于宋时，有徐子平者，得虚中之术，损益之，专主五行，不主纳音，至是则其法又一变也。"

**论十神**：
> "以日为主，而取年月时之天干地支所藏，配合为用。我克者为财，克我者为官，我生者为子，生我者为父母，同我者为兄弟。"

**论格局**：
> "取格者，以月令为主。月令者，提纲也。看月令中地支所藏何物，透出天干，即以何物为格。"

### 1.5 研读建议

- 入门首选，全文通读
- 重点研读卷一（基础）、卷二（十神）、卷三（格局）
- 赋文歌诀须背诵
- 命例部分反复揣摩

## 二、《三命通会》

### 2.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《三命通会》 |
| **作者** | 万民英（明） |
| **成书年代** | 明万历年间（1578年） |
| **卷数** | 十二卷 |
| **地位** | 命理学百科全书、集大成之作 |

### 2.2 内容概要

《三命通会》是命理学上规模最大、内容最全面的著作，堪称命理学的"百科全书"。万民英广收博采，将宋代以来三百余年的命理文献熔于一炉，兼收并蓄，内容宏富。

**各卷内容**：

- **卷一**：论天干地支、纳音、五行生克、六十甲子
- **卷二**：论排盘、节气、时辰、命宫、胎元
- **卷三**：论十神、论六亲、论神煞
- **卷四**：论格局（正格）、论用神
- **卷五**：论格局（变格）、论外格
- **卷六**：论大运、论太岁、论流年
- **卷七**：论女命、论小儿命
- **卷八**：论六甲日、论六乙日（六十甲子日各论）
- **卷九至卷十二**：六十甲子日各论续、命例汇编、赋文歌诀

### 2.3 核心贡献

1. **集大成**：汇集宋元明三代命理精华，内容最为全面
2. **六十甲子日论**：首创逐日论命法，对六十甲子各日进行详细分析
3. **神煞系统**：系统整理神煞，为后世神煞论命提供依据
4. **女命论**：专论女命推演法则，为女命研究奠定基础

### 2.4 经典原文（节选）

**论命之总纲**：
> "夫命者，禀天地之气，受五行之精。人禀天地，命属阴阳。生居覆载之中，尽在五行之内。欲知贵贱，先观月令提纲；次断吉凶，专用日干为主。"

**论大运**：
> "大运者，人生之传舍。命犹舟也，运犹水也。水能载舟，亦能覆舟。运之吉凶，关乎一生之休咎。"

**论用神**：
> "用神者，命之枢纽也。用神得地，则一生富贵；用神失地，则一生困顿。用神不可损伤，损伤则凶。"

### 2.5 研读建议

- 命理进阶必读
- 可作工具书查阅，不必通读
- 重点研读卷三（十神）、卷四至卷五（格局）、卷六（大运流年）
- 六十甲子日论作为参考，不可拘泥

## 三、《命理探源》

### 3.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《命理探源》 |
| **作者** | 袁树珊（清末民初） |
| **成书年代** | 民国初年（1915年） |
| **卷数** | 八卷 |
| **地位** | 近现代命理学规范之作 |

### 3.2 内容概要

《命理探源》是清末民初著名命理学家袁树珊的代表作。袁氏以"考据"之法，对命理学的源流、术语、方法进行了系统梳理和规范，使命理学从"玄学"走向"学术"。

**各卷内容**：

- **卷一**：排盘法
- **卷二**：格局篇
- **卷三**：十神篇
- **卷四**：用神篇
- **卷五**：大运篇
- **卷六**：流年篇
- **卷七**：神煞篇
- **卷八**：命例篇

### 3.3 核心贡献

1. **考据源流**：对命理学术语和方法的来源进行了考证，正本清源
2. **规范排盘**：建立系统化的排盘方法，包括真太阳时校正
3. **用神体系**：完善用神理论，系统阐述扶抑、调候、通关、病药四法
4. **命例分析**：收录大量现代命例，理论与实践结合

### 3.4 经典原文（节选）

**论排盘**：
> "排盘之法，首重时刻。时刻不准，则全盘皆错。故须以真太阳时为准，不可拘泥于钟表之时。"

**论用神**：
> "用神者，命之枢纽也。取用之法有四：一曰扶抑，二曰调候，三曰通关，四曰病药。四者之中，以扶抑为最要，调候次之，通关又次之，病药为变通之法。"

**论大运**：
> "大运者，十年之休咎也。大运重地支，流年重天干。大运管十年，五年分上下。前五年以天干为主，后五年以地支为主。"

### 3.5 研读建议

- 现代命理入门必读
- 排盘法、用神篇重点研读
- 命例篇反复揣摩，学习分析思路
- 考据部分不必深究，了解即可

## 四、《滴天髓》

### 4.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《滴天髓》 |
| **作者** | 京图（宋，一说托名）/ 刘伯温（明）注 / 任铁樵（清）疏 |
| **成书年代** | 原文约宋代，任铁樵疏注于清道光年间 |
| **卷数** | 原文一卷，任注本四卷 |
| **地位** | 命理学"圣经"、理论最高峰 |

### 4.2 内容概要

《滴天髓》原文极为精炼，以赋文形式阐述命理精义，文字玄奥，义理深邃。经明代刘伯温作注、清代任铁樵作疏后，成为命理学理论深度最高的著作，被誉为"命学圣经"。

**任铁樵注本内容**：

- **上卷：通神论**：天道、地道、人道、知命、理气、配合、天干、地支、干支总论、形象、方局、八格、体用、精神、月令、生时、衰旺、中和、源流、通关、官杀、伤官、清气、浊气、真神、假神、刚柔、顺逆、寒暖、燥湿、隐显、众寡、震兑、坎离
- **下卷：六亲论**：夫妻、子女、兄弟、父母、出身、地位、贫富、贵贱、吉凶、寿夭、性情、疾病、出身、女命、小儿

### 4.3 核心贡献

1. **理论高峰**：命理学理论深度的最高成就，哲学思辨与命理技术完美结合
2. **中和之道**：强调中和平衡，反对极端片面
3. **形象思维**：以"形象"比喻命局，深刻生动
4. **寒暖燥湿**：系统论述调候理论，寒暖燥湿为命局大要
5. **源流通关**：论述五行流通之理，源流清浊定贵贱

### 4.4 经典原文（节选）

**天道篇**：
> "欲识三元万法宗，先观帝载与神功。"

**地道篇**：
> "坤元合德机缄通，五气偏全定吉凶。"

**人道篇**：
> "戴天履地人为贵，顺则吉兮凶则悖。"

**天干论**：
> "五阳皆阳丙为最，五阴皆阴癸为至。五阳从气不从势，五阴从势无情义。"

**地支论**：
> "阳支动且强，速达显灾祥；阴支静且专，否泰每经年。"

**格局论**：
> "财官印绶分偏正，兼论食伤八格定。影响遥系既为虚，杂气财官不可拘。"

**寒暖论**：
> "天道有寒暖，发育万物，人道得之不可过也。地道有燥湿，生成品汇，人道得之不可偏也。"

**顺逆论**：
> "顺逆不齐，不可逆者，其气势而已矣。刚柔之道，可顺而不可逆也。"

**源流论**：
> "何处起根源，流到何方住。机括此中求，知来亦知去。"

### 4.5 研读建议

- 命理高级研读，不建议入门即读
- 须在掌握《渊海子平》《三命通会》基础后再研读
- 任铁樵疏注为必读版本，刘伯温注为辅
- 需反复研读，每读一遍都有新体会
- 配合命例实践，方能融会贯通

## 五、《子平真诠》

### 5.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《子平真诠》 |
| **作者** | 沈孝瞻（清） |
| **成书年代** | 清乾隆年间（约1740年） |
| **卷数** | 五卷 |
| **地位** | 格局论命之集大成、子平正法之典范 |

### 5.2 内容概要

《子平真诠》以格局论命为核心，系统阐述"用神"概念，对《渊海子平》以来的格局论命法进行了全面总结和升华。沈氏以"用神"为纲领，以"格局"为框架，构建了一套完整的命理分析体系。

**各卷内容**：

- **卷一**：论阴阳生克、论十干十二支、论干支生克、论用神、论用神成败救应、论用神变化、论用神纯杂、论用神格局高低
- **卷二**：论正官、论正官格、论财格、论财官印绶、论印绶格、论食神格、论食神格之变
- **卷三**：论七杀、论七杀格、论伤官、论伤官格、论阳刃、论建禄月劫
- **卷四**：论用神配气候得失、论用神先后、论用神因成得败因败得成、论宫分用神、论妻子、论行运、论行运成格变格
- **卷五**：论杂格、论星辰无关格局、论外格用舍、论时说拘泥格局、论时说以讹传讹

### 5.3 核心贡献

1. **用神体系**：以"用神"统摄格局，使格局论命有了统一的逻辑核心
2. **格局精微**：对八种正格进行了极为精微的分析，论格最细
3. **顺逆之道**：善者顺用，不善者逆用，为格局论命的总纲领
4. **成败救应**：用神的成败、救应、变化，为命局分析提供了细致入微的方法
5. **正本清源**：对当时流行的各种谬说进行了批判，回归子平正法

### 5.4 经典原文（节选）

**论用神**：
> "八字用神，专求月令。以日干配月令地支，而生克不同，格局分焉。财官印食，此用神之善而顺用之者也；杀伤枭刃，此用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。"

**论用神成败救应**：
> "用神既定，则须观其成败救应。成中有败，必为带疾；败中有成，反为得福。何谓成？用神得地是也。何谓败？用神被伤是也。何谓救应？制其伤者是也。"

**论用神格局高低**：
> "格局有高低，用神有真假。何谓真假？得时秉令者为真，失时退气者为假。真者贵，假者贱。然真假之中，又有高低之分。"

**论行运**：
> "运之善者，利于用神；运之不善者，不利于用神。行运之中，有喜有忌。喜者，生用神之运也；忌者，克用神之运也。"

### 5.5 研读建议

- 格局论命必读经典
- 须在掌握十神基础后再研读
- 重点研读卷一（用神总论）、卷二（正格各论）、卷四（行运论）
- 反复揣摩"善者顺用、不善者逆用"的总纲领
- 配合命例实践，体会格局论命之精微

## 六、五大经典对比总结

| 维度 | 渊海子平 | 三命通会 | 命理探源 | 滴天髓 | 子平真诠 |
|------|---------|---------|---------|--------|---------|
| **年代** | 南宋 | 明万历 | 民国初 | 宋-清 | 清乾隆 |
| **定位** | 奠基之作 | 百科全书 | 规范之作 | 理论巅峰 | 格局集大成 |
| **特色** | 体系开创 | 广博全面 | 考据规范 | 哲思深邃 | 格局精微 |
| **难度** | 入门 | 中等 | 中等 | 高深 | 中高 |
| **核心** | 十神+格局 | 六十甲子日 | 排盘+用神 | 中和+形象 | 用神+格局 |
| **适合** | 初学者 | 查阅参考 | 进阶研读 | 高阶研读 | 格局研读 |

### 研读顺序建议

1. **入门**：《渊海子平》 → 建立基本概念和框架
2. **进阶**：《命理探源》 → 规范排盘方法，深入理解用神
3. **深化**：《子平真诠》 → 精研格局论命
4. **扩展**：《三命通会》 → 作为工具书随时查阅
5. **升华**：《滴天髓》 → 领悟命理哲学，提升境界
