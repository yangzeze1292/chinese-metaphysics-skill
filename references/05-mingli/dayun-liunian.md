# 大运流年分析

> 命局为体，大运为用，流年为引。命局定一世之根基，大运主十年之顺逆，流年应一年之吉凶。三者结合，方能断命之精微。

---

## 一、大运排法

### 1.1 大运顺逆

大运的排列方向由年干阴阳和性别决定：

| 年干 | 性别 | 排法 | 说明 |
|------|------|------|------|
| 阳年（甲丙戊庚壬） | 男 | 顺排 | 从月柱顺数至下一节气 |
| 阳年（甲丙戊庚壬） | 女 | 逆排 | 从月柱逆数至上一节气 |
| 阴年（乙丁己辛癸） | 男 | 逆排 | 从月柱逆数至上一节气 |
| 阴年（乙丁己辛癸） | 女 | 顺排 | 从月柱顺数至下一节气 |

**口诀**：

> 阳男阴女顺行，阴男阳女逆行。

### 1.2 起运岁数

起运岁数由出生日距上一个或下一个节气的天数决定：

```
起运岁数 = 天数 ÷ 3
```

- 三天为一年
- 一天为四个月（即1/3岁）
- 一个时辰为十天

**顺排者**：从出生日顺数至下一个节气，计天数，除以3，得岁数。
**逆排者**：从出生日逆数至上一个节气，计天数，除以3，得岁数。

**注意**：此处说的是"节"而非"气"。二十四节气中，节为每月的开始（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），气为每月的中气。起运以节为界。

### 1.3 大运干支排列

起运岁数确定后，大运干支从月柱顺推或逆推，每运十年。

**顺排**：月柱干支顺推，如月柱为己卯，则：
- 第一步大运：庚辰
- 第二步大运：辛巳
- 第三步大运：壬午
- ……

**逆排**：月柱干支逆推，如月柱为己卯，则：
- 第一步大运：戊寅
- 第二步大运：丁丑
- 第三步大运：丙子
- ……

### 1.4 大运排列实例

**例**：某男命，生于甲年（阳年）丙寅月，顺排。出生日距下一个节气（惊蛰）15天。

- 起运岁数：15 ÷ 3 = 5岁起运
- 大运排列：

| 大运 | 干支 | 年龄段 |
|------|------|--------|
| 第一步 | 丁卯 | 5-14岁 |
| 第二步 | 戊辰 | 15-24岁 |
| 第三步 | 己巳 | 25-34岁 |
| 第四步 | 庚午 | 35-44岁 |
| 第五步 | 辛未 | 45-54岁 |
| 第六步 | 壬申 | 55-64岁 |
| 第七步 | 癸酉 | 65-74岁 |
| 第八步 | 甲戌 | 75-84岁 |

## 二、大运与命局关系

### 2.1 大运为君，命局为民

大运以十年为期，主宰人生各阶段的运势走向。命局为根本，大运为变化。

> 《滴天髓》："运之顺逆，如舟之顺流逆流，顺则易达，逆则多阻。"

### 2.2 大运喜忌

**大运与用神的关系**：
- 大运为用神或喜神：此十年顺遂，事业有成，财官两旺
- 大运为忌神：此十年波折，多灾多难，事业受阻
- 大运生用神：运势上升，渐入佳境
- 大运克用神：运势下降，由盛转衰

**大运的关键节点**：
- 交运之年（换大运的年份）：运势剧烈变化，吉凶转折
- 大运上半段（前五年，天干主事）：天干之力为主
- 大运下半段（后五年，地支主事）：地支之力为主

> 《命理探源》："大运重地支，流年重天干。大运管十年，五年分上下。"

### 2.3 大运与命局格局

- **命好运好**：富贵双全，一生顺遂
- **命好运差**：怀才不遇，机遇未至
- **命差运好**：虽出身平凡，但得时运相助，终有所成
- **命差运差**：一生困顿，难有出头之日

> 《三命通会》："命好不如运好，运好不如流年好。命好运好，富贵到老；命好运不好，富贵不长久。"

### 2.4 大运干支分论

**大运天干**：
- 前五年以天干为主
- 天干之力外显，主外在环境、贵人、机遇
- 天干为用神，则前五年顺遂

**大运地支**：
- 后五年以地支为主
- 地支之力内敛，主内在条件、根基、实力
- 地支为用神，则后五年平稳

**干支配合**：
- 干支相生：大运有力，顺遂
- 干支相克：大运斗争，波折
- 干支同气：大运专一，力量集中

## 三、流年引动

### 3.1 流年总论

流年（太岁）为一年之主，主宰一年之吉凶。流年与命局、大运三者结合，方能断一年之详细。

> 《渊海子平》："太岁乃年中天子，故不可犯，犯之则凶。"

### 3.2 流年与大运、命局的互动

**流年与大运**：
- 流年生大运：一年顺遂，运势上升
- 大运生流年：运势平稳，有所收获
- 流年与大运同气：力量集中，吉凶加倍
- 流年克大运：一年波折，运势受阻
- 大运克流年：运势尚可，但需小心应对

**流年与命局**：
- 流年为用神：一年吉利，所求顺遂
- 流年为忌神：一年不利，多有波折
- 流年冲日柱：多有变动（搬家、换工作、出行等）
- 流年合日柱：多有喜事（婚嫁、合作、得财等）

### 3.3 岁运并临

岁运并临，即流年干支与大运干支完全相同。

**岁运并临的吉凶**：
- 岁运并临为用神：大吉，力量加倍，所求皆遂
- 岁运并临为忌神：大凶，力量加倍，灾祸临头
- 岁运并临为喜神：吉祥，事业有成
- 岁运并临五行被命局所喜：好运加倍
- 岁运并临冲克命局关键干支：大凶

> 《滴天髓》："岁运并临，吉者愈吉，凶者愈凶。"

### 3.4 流年天干与地支

- **流年天干**：主外在事件、机遇、名声，一年中前半年（春夏）为主
- **流年地支**：主内在条件、根基、实质，一年中后半年（秋冬）为主
- **天干地支同气**：力量集中，事件明显
- **天干地支相克**：表里不一，内外矛盾

## 四、天干地支合冲刑害

### 4.1 天干五合

**五合表**：

| 合 | 组合 | 化气 | 说明 |
|----|------|------|------|
| 甲己合 | 甲 + 己 | 土 | 中正之合 |
| 乙庚合 | 乙 + 庚 | 金 | 仁义之合 |
| 丙辛合 | 丙 + 辛 | 水 | 威制之合 |
| 丁壬合 | 丁 + 壬 | 木 | 淫慝之合 |
| 戊癸合 | 戊 + 癸 | 火 | 无情之合 |

**合化条件**：
- 化神在月令得令（旺相），化气方真
- 天干合化成功，两个天干失去原有五行属性，变为化神五行
- 若化神不得令，则合而不化，为"合绊"（两干被合住，力量减弱）

**合化在命局中的意义**：
- 日干合化：日主化气，按化气格论命
- 用神被合：用神失去作用，不吉
- 忌神被合：忌神被制，转吉
- 合绊：两干互绊，力量减弱，喜忌皆减力

**大运流年中的合**：
- 大运天干与命局天干合：十年中有合化之事
- 流年天干与命局天干合：一年中有合化之事
- 流年天干与大运天干合：一年中运势变化的关键

### 4.2 地支六合

**六合表**：

| 合 | 组合 | 化气 | 说明 |
|----|------|------|------|
| 子丑合 | 子 + 丑 | 土 | 子丑合土 |
| 寅亥合 | 寅 + 亥 | 木 | 寅亥合木 |
| 卯戌合 | 卯 + 戌 | 火 | 卯戌合火 |
| 辰酉合 | 辰 + 酉 | 金 | 辰酉合金 |
| 巳申合 | 巳 + 申 | 水 | 巳申合水 |
| 午未合 | 午 + 未 | 土 | 午未合土 |

**六合在命局中的意义**：
- 地支六合加强合化五行之力
- 合化的两支失去原有部分力量
- 合而不化则两败俱伤，力量减弱
- 六合主合作、结合、牵连之事

**大运流年中的六合**：
- 大运地支与命局地支六合：十年中有合化之事
- 流年地支与命局地支六合：一年中有合作、婚恋之事
- 流年地支与日支六合：感情婚姻之事，或合作之事

### 4.3 地支三合

**三合局**：

| 三合局 | 组合 | 五行 |
|--------|------|------|
| 申子辰 | 申 + 子 + 辰 | 水局 |
| 亥卯未 | 亥 + 卯 + 未 | 木局 |
| 寅午戌 | 寅 + 午 + 戌 | 火局 |
| 巳酉丑 | 巳 + 酉 + 丑 | 金局 |

**三合条件**：
- 三字齐全，方能成局
- 半合（两字，如申子、子辰）亦有力，但不如三字齐全
- 合化须在命局、大运或流年中凑齐

**三合在命局中的意义**：
- 三合局力量极大，改变命局五行结构
- 三合成局，该五行力量剧增
- 三合局为用神所喜，大吉；为忌神所喜，大凶
- 三合局主团体、联盟、整合之事

**大运流年中的三合**：
- 大运补齐命局中缺失的三合之字，十年中成局
- 流年补齐命局中缺失的三合之字，一年中成局
- 三合局冲克日主或关键干支，变动剧烈

### 4.4 地支三会

**三会方**：

| 三会方 | 组合 | 五行 | 方位 |
|--------|------|------|------|
| 寅卯辰 | 寅 + 卯 + 辰 | 木 | 东方 |
| 巳午未 | 巳 + 午 + 未 | 火 | 南方 |
| 申酉戌 | 申 + 酉 + 戌 | 金 | 西方 |
| 亥子丑 | 亥 + 子 + 丑 | 水 | 北方 |

**三会特点**：
- 三会方力量大于三合局，为最强之地支组合
- 三会方代表方位之力，是全局性的力量重组
- 命局中若有三会方，该五行力量极强，几乎主导全局

**大运流年中的三会**：
- 大运或流年补齐三会之字，该年力量激增
- 三会方为用神，大吉大利；为忌神，大灾大难

**六冲表**：

|----|------|------|

**冲的含义**：
- 冲主动荡、变动、冲突、分离
- 冲的力量大于合，冲主动，合主静
- 冲能解合，合能解冲，看谁先到

**命局中的冲**：
- 年柱与月柱冲：早年离家，祖业不靠
- 日支与月支冲：婚姻多变，事业不稳
- 日支与时支冲：晚年婚姻变动，子女远离

**大运流年中的冲**：
- 大运冲命局：十年中变动剧烈
- 流年冲大运：一年中运势动荡
- 流年冲日柱：该年多有变动（搬家、换工作、远行）
- 流年冲年柱：长辈之事，或有远行
- 流年冲月柱：工作变动，事业起伏
- 流年冲时柱：子女之事，晚年变动

> 《三命通会》："冲者，动也。冲主动，合主静。冲主动荡，合主安宁。"

## 五、岁运并临与特殊组合

### 5.1 岁运并临

岁运并临，即流年干支与大运干支完全相同。这是大运流年组合中最特殊的一种。

**岁运并临的详细分析**：

| 条件 | 吉凶 | 说明 |
|------|------|------|
| 岁运并临为用神/喜神 | 大吉 | 力量加倍，所求皆遂，事业腾达 |
| 岁运并临为忌神 | 大凶 | 灾祸加倍，防不胜防 |
| 岁运并临冲克日柱 | 凶 | 该年变动剧烈，多有灾祸 |
| 岁运并临合日柱 | 吉 | 该年有喜事，或合作得利 |
| 岁运并临临太岁 | 加重 | 临太岁者力量更强 |

> 《命理探源》："岁运并临，不死自己死他人。此言岁运并临为忌神时之凶险也。"

### 5.2 天克地冲

天克地冲，即流年天干克大运天干（或命局天干），同时流年地支冲大运地支（或命局地支）。

**天克地冲的吉凶**：
- 天克地冲用神：大凶，一年动荡，灾祸不断
- 天克地冲忌神：因祸得福，反而转吉
- 天克地冲日柱：该年变动剧烈，婚姻、事业、健康均有影响

### 5.3 天地鸳鸯合

流年天干合命局/大运天干，流年地支合命局/大运地支，谓之天地鸳鸯合。

**天地鸳鸯合的吉凶**：
- 合为用神/喜神：大吉，一年喜事连连
- 合为忌神：被合绊，虽不吉但不至于大凶
- 合日柱：婚姻感情之事，或合作喜事

### 5.4 伏吟与反吟

- **伏吟**：流年与命局某柱干支相同（如日柱为甲寅，流年亦为甲寅），主该年该柱所主之事有反复
- **反吟**：流年与命局某柱天克地冲（如日柱为甲寅，流年为庚申），主该年变动剧烈

**伏吟反吟歌诀**：
> 伏吟反吟，涕泪淋淋。不伤自己，也伤他人。

## 六、大运流年综合分析实例

**例**：命主八字为乙丑 己卯 癸丑 己未，大运丙子（23-32岁），流年庚子年。

**分析步骤**：

1. **大运分析**：丙子大运，丙为日主癸水之正财，子为日主癸水之比肩。正财运，此十年以财运为主，子水比肩助身，身强能任财。

2. **流年分析**：庚子年，庚为日主癸水之正印，子为日主癸水之比肩。印星生身，比肩助身，身旺之年。

3. **岁运关系**：大运丙子，流年庚子
   - 天干：流年庚金（正印）克大运丙火（正财），为"印克财"
   - 地支：流年子水与大运子水相同，为"岁运并临"中的地支并临
   - 印克财：此年学业、名誉方面有进展，但财运有所损耗

4. **流年与命局**：
   - 流年庚子与日柱癸丑：庚生癸（印生身），子丑合（比肩合日支）
   - 子丑合：日支被合，感情婚姻有喜事或变动
   - 印生身：此年有贵人相助，学业/事业有所提升

5. **综合判断**：
   - 此年印旺身强，学业事业有进展
   - 印克财，财运有损，但印为善神，损财为投资学习
   - 子丑合，感情婚姻有喜
   - 总体：吉大于凶，为发展之年
