# 互卦与变卦分析

## 概说

梅花易数占断，以本卦为始，以互卦为过程，以变卦为终结。三卦相参，方能洞悉事物之全貌。邵雍《梅花易数》曰：

> 凡占卜，以本卦为事之始，互卦为事之中，变卦为事之终。三者合观，则吉凶判然。

又曰：

> 本卦者，事之初始也；互卦者，事之中间也；变卦者，事之末后也。三者合而观之，则吉凶悔吝，一目了然。

---

## 一、互卦取法

### 1.1 互卦的定义

互卦，又称"中爻卦"、"互体卦"，是由本卦中间四爻重新组合而成的卦。本卦六爻，去掉初爻（最下）和上爻（最上），以中间四爻组成互卦。

**《梅花易数》原文**：

> 互卦者，重卦中去初爻、上爻，以中间四爻分作两卦。以二爻、三爻、四爻为下互，以三爻、四爻、五爻为上互。上互与下互合而为互卦。

### 1.2 互卦的取法规则

从本卦六爻之中，取中间四爻（二、三、四、五爻），重新组合：

- **下互卦（内互）**：取本卦的 **第二爻、第三爻、第四爻** 组成下互卦的三爻。其中，第二爻为下互卦的初爻，第三爻为下互卦的二爻，第四爻为下互卦的三爻。

- **上互卦（外互）**：取本卦的 **第三爻、第四爻、第五爻** 组成上互卦的三爻。其中，第三爻为上互卦的初爻，第四爻为上互卦的二爻，第五爻为上互卦的三爻。

- **互卦**：上互卦在上，下互卦在下，组成完整的六爻互卦。

### 1.3 互卦取法图解

以本卦六爻结构为例：

```
本卦结构：
  上爻  ───
  五爻  ───  ← 上互卦第三爻
  四爻  ───  ← 上互卦第二爻 / 下互卦第三爻
  三爻  ───  ← 上互卦初爻   / 下互卦第二爻
  二爻  ───  ←               下互卦初爻
  初爻  ───  (去掉)

互卦结构：
  上互卦第三爻 = 本卦五爻
  上互卦第二爻 = 本卦四爻  ─── 上互卦
  上互卦初爻   = 本卦三爻
  
  下互卦第三爻 = 本卦四爻
  下互卦第二爻 = 本卦三爻  ─── 下互卦
  下互卦初爻   = 本卦二爻
```

注意：本卦的第三爻和第四爻，同时参与了上互卦和下互卦的构建。

### 1.4 互卦取法示例

**示例一**：本卦为天火同人（上乾下离）。

```
本卦天火同人：
  上爻 ───── 阳
  五爻 ───── 阳
  四爻 ───── 阳  ← 乾卦
  三爻 ─── ── 阴
  二爻 ─── ── 阴  ← 离卦
  初爻 ───── 阳

取互卦：
  下互卦：二爻(阴) + 三爻(阴) + 四爻(阳) = 巽卦（☴）
  上互卦：三爻(阴) + 四爻(阳) + 五爻(阳) = 乾卦（☰）

  互卦 = 上乾下巽 = 天风姤
```

**示例二**：本卦为雷水解（上震下坎）。

```
本卦雷水解：
  上爻 ─── ── 阴
  五爻 ─── ── 阴
  四爻 ───── 阳  ← 震卦
  三爻 ─── ── 阴
  二爻 ───── 阳  ← 坎卦
  初爻 ─── ── 阴

取互卦：
  下互卦：二爻(阳) + 三爻(阴) + 四爻(阳) = 离卦（☲）
  上互卦：三爻(阴) + 四爻(阳) + 五爻(阴) = 坎卦（☵）

  互卦 = 上坎下离 = 水火既济
```

**示例三**：本卦为地雷复（上坤下震）。

```
本卦地雷复：
  上爻 ─── ── 阴
  五爻 ─── ── 阴
  四爻 ─── ── 阴  ← 坤卦
  三爻 ─── ── 阴
  二爻 ─── ── 阴  ← 震卦（注意：震卦二阴一阳在下）
  初爻 ───── 阳  （已去除）

取互卦：
  下互卦：二爻(阴) + 三爻(阴) + 四爻(阴) = 坤卦（☷）
  上互卦：三爻(阴) + 四爻(阴) + 五爻(阴) = 坤卦（☷）

  互卦 = 上坤下坤 = 坤为地
```

### 1.5 互卦的占断意义

互卦代表事物发展过程中的中间状态，是连接本卦（初始）与变卦（结果）的桥梁。

**《梅花易数》原文**：

> 互卦者，事之中也。本卦为始，变卦为终，互卦乃中间之应。凡占事，勿只观本卦与变卦，须兼看互卦。互卦生体则中途顺利，互卦克体则中途有阻。

**互卦在占断中的应用**：
- 互卦克体：事物发展过程中遇阻碍，需谨慎行事。
- 互卦生体：中途有贵人相助，事情进展顺利。
- 互卦与体比和：中途平稳，无大起大落。
- 互卦体用生克关系，对照体用生克篇综合判断。

## 二、变爻规则

### 2.1 变爻的基本概念

变爻，即动爻。在梅花易数中，动爻只有一爻。动爻之阴阳发生反转（阳变阴、阴变阳），从而产生变卦。

**《梅花易数》原文**：

> 动爻者，变也。阳动变阴，阴动变阳。一爻动则一卦变，所谓变卦是也。

### 2.2 变爻的确定方法

变爻（动爻）由起卦时的规则确定，常见方法已在"起卦法"中详述，此处不再重复。核心通则：

- 总起卦数（或特定数）除以 6，余数即动爻位置。
- 余 1 = 初爻动，余 2 = 二爻动，……，余 5 = 五爻动，整除（余 0）= 上爻动。

### 2.3 变卦的产生

动爻所在的经卦（三爻卦）发生阴阳反转后，该经卦变为另一个经卦。由此，本卦变为变卦。

**变卦产生规则**：

1. 确定动爻在本卦中的位置（初爻至上爻）。
2. 将该爻的阴阳反转：阳爻（─────）变为阴爻（── ──），阴爻（── ──）变为阳爻（─────）。
3. 动爻所在的经卦（上卦或下卦）随之发生变化，产生新的经卦。
4. 新的上卦与下卦组合，即为变卦（也称"之卦"）。

### 2.4 变卦示例

**示例一**：本卦天火同人（上乾下离），动爻在二爻。

```
本卦天火同人：          变卦天风姤：
  上爻 ───── 阳 (乾)      上爻 ───── 阳 (乾)
  五爻 ───── 阳            五爻 ───── 阳
  四爻 ───── 阳            四爻 ───── 阳
  三爻 ─── ── 阴 (离)      三爻 ─── ── 阴 (巽)
  二爻*── ── 阴 → 变阳     二爻 ───── 阳
  初爻 ───── 阳            初爻 ─── ── 阴

离卦(☲)中爻动 → 离变巽(☴)，变卦为天风姤
```

**示例二**：本卦地雷复（上坤下震），动爻在初爻。

```
本卦地雷复：            变卦地泽临：
  上爻 ─── ── 阴 (坤)      上爻 ─── ── 阴 (坤)
  五爻 ─── ── 阴            五爻 ─── ── 阴
  四爻 ─── ── 阴            四爻 ─── ── 阴
  三爻 ─── ── 阴 (震)       三爻 ─── ── 阴 (兑)
  二爻 ─── ── 阴            二爻 ───── 阳
  初爻*───── 阳 → 变阴      初爻 ─── ── 阴

震卦(☳)初爻动 → 震变兑(☱)，变卦为地泽临
```

### 2.5 六爻皆静的情形

在梅花易数中，六爻皆静的情况较为特殊。此时：

- 以本卦为占断的主体，无变卦。
- 体用之分：上卦为用，下卦为体。
- 仍可取互卦辅助分析过程。
- 若需看变卦，则可以本卦的上卦为变卦，或以本卦为变卦（即本卦即变卦）。

## 三、综卦与错卦

### 3.1 综卦（覆卦）

**定义**：综卦，又称"覆卦"、"反卦"，是将本卦六爻完全颠倒过来（上下翻转）所得到的卦。

**《周易》原文**：

> 八卦相错，数往者顺，知来者逆，是故易逆数也。

**综卦取法**：将本卦的六爻顺序完全颠倒，初爻变为上爻，二爻变为五爻，三爻变为四爻，四爻变为三爻，五爻变为二爻，上爻变为初爻。

**综卦对应对照表**：

| 本卦 | 综卦 | 说明 |
|------|------|------|
| 乾为天 | 乾为天 | 乾卦自综 |
| 坤为地 | 坤为地 | 坤卦自综 |
| 震为雷 | 艮为山 | 震艮互为综 |
| 巽为风 | 兑为泽 | 巽兑互为综 |
| 坎为水 | 坎为水 | 坎卦自综 |
| 离为火 | 离为火 | 离卦自综 |
| 艮为山 | 震为雷 | 艮震互为综 |
| 兑为泽 | 巽为风 | 兑巽互为综 |

**综卦的占断意义**：

综卦表示从对方（或反面）的角度看问题。在占断中：

- 综卦与体卦的关系：反映对方的态度和立场。
- 综卦与用卦的关系：反映事情的反面影响。
- 若综卦克体，则需注意对方不利的动向。
- 综卦可辅助判断事情的"另一面"。

### 3.2 错卦（旁通卦）

**定义**：错卦，又称"旁通卦"、"变卦之变"，是将本卦六爻阴阳全部反转所得到的卦。阳爻全变阴爻，阴爻全变阳爻。

**错卦取法**：将本卦的每一爻阴阳反转，即"阳变阴，阴变阳"。

**错卦对应对照表**：

| 本卦 | 错卦 | 说明 |
|------|------|------|
| 乾为天（☰☰） | 坤为地（☷☷） | 乾坤互错 |
| 兑为泽（☱☱） | 艮为山（☶☶） | 兑艮互错 |
| 离为火（☲☲） | 坎为水（☵☵） | 离坎互错 |
| 震为雷（☳☳） | 巽为风（☴☴） | 震巽互错 |

**错卦的占断意义**：

错卦是一种"隐伏"之象，代表事物潜在的、暗藏的另一面。在占断中：

- 错卦反映隐伏的危机或机遇。
- 错卦生体：有暗中的助力或未曾察觉的好运。
- 错卦克体：有暗藏的危机或潜在的敌人。
- 用卦的错卦，可以反映事情深层次的原因。
- 错卦属于高级占断技巧，一般初学者先以本卦、互卦、变卦为主。

### 3.3 综卦与错卦的取法示例

**示例**：以"天火同人"（上乾下离）为例。

```
本卦：天火同人
  上卦 乾 ☰ ───── 阳
                ───── 阳
                ───── 阳
  下卦 离 ☲ ───── 阳
                ─── ── 阴
                ───── 阳

综卦：火天大有（上离下乾）—— 上下颠倒
  上卦 离 ☲ ───── 阳
                ─── ── 阴
                ───── 阳
  下卦 乾 ☰ ───── 阳
                ───── 阳
                ───── 阳

错卦：地水师（上坤下坎）—— 阴阳全反
  上卦 坤 ☷ ─── ── 阴
                ─── ── 阴
                ─── ── 阴
  下卦 坎 ☵ ─── ── 阴
                ───── 阳
                ─── ── 阴
```

## 四、本卦、互卦、变卦综合占断

### 4.1 三卦占断的层次

梅花易数占断，通常以"本卦—互卦—变卦"三层结构进行分析：

| 卦 | 意义 | 占断重点 |
|----|------|---------|
| **本卦** | 事之初始 | 当前状况、问题的起因 |
| **互卦** | 事之中间 | 发展过程、中间变化 |
| **变卦** | 事之终结 | 最终结果、未来的走向 |

### 4.2 综合占断流程

**第一步：明体用**

以本卦确定体卦与用卦，判断体用生克关系。这是整个占断的根基。

**第二步：观互卦**

看互卦与体卦的生克关系，判断事物发展过程中是否顺利，有无阻碍或助力。

**第三步：审变卦**

看变卦与体卦（注意：变卦中体用关系可能发生变化，需重新判断）的生克关系，判断最终结果。

**第四步：参外应**

结合占卜时的外应（时间、环境、所见之物等），以及综卦、错卦，综合判断。

### 4.3 综合占断示例

**示例**：某人占问求职，得本卦火雷噬嗑（上离下震），动爻在四爻。

**第一步：分析本卦**

```
本卦：火雷噬嗑
  上卦离（火）：动爻在四爻，故用卦 = 离火
  下卦震（木）：不动，故体卦 = 震木
  体用关系：木生火 → 体生用 → 小凶，有耗散之忧
```

占断：求职需付出较多心力，可能有耗散之虞。

**第二步：取互卦**

```
本卦火雷噬嗑：
  上爻 ───── 阳
  五爻 ─── ── 阴
  四爻*───── 阳  ← 动爻
  三爻 ─── ── 阴
  二爻 ─── ── 阴
  初爻 ───── 阳

下互卦：二爻(阴) + 三爻(阴) + 四爻(阳) = 艮卦（☶）
上互卦：三爻(阴) + 四爻(阳) + 五爻(阴) = 坎卦（☵）
互卦：上坎下艮 = 水山蹇
```

互卦水山蹇，蹇者难也。坎水克艮土，互卦体用之间亦有克制。说明求职过程中会遇到困难阻碍。

**第三步：取变卦**

动爻在四爻（上卦离之中爻），离卦中爻阳变阴：

```
离卦(☲)：中爻阳变阴 → 艮卦(☶)
变卦：上艮下震 = 山雷颐
```

变卦山雷颐，颐者养也。重新判断体用：变卦中上卦艮为动爻所在，故用卦 = 艮土，体卦 = 震木。木克土 → 体克用 → 小吉，事可成但费力。

**第四步：综合判断**

- 本卦体生用（小凶）：求职需付出，有耗散。
- 互卦水山蹇（过程有阻）：面试或等待过程有波折。
- 变卦体克用（小吉）：最终可获职位，但过程不易，需坚持。

**最终结论**：求职可成，但过程不顺，需多番努力，恐有面试被拒或等待时间较长的情况。最终能获得职位，但待遇可能不如预期。
