# 周公解梦经典 · Zhou Gong Dream Dictionary Reference

> 《周公解梦》是中国解梦学的源头，相传为周公（姬旦）所著，后经历代整理增补。本文件收录《周公解梦》中常见梦象的经典断辞原文，供解梦时引用参考。

## 十、使用说明

1. **不可机械套用**：以上断辞为传统参考，需结合梦者个人情况灵活解读
2. **注意反义**：部分梦象（如哭泣、棺材）在周公解梦中为反义，梦悲反喜，梦死反生
3. **情绪优先**：梦中的情绪比具体符号更重要，断辞仅供参考
4. **标注出处**：引用时请标注"据《周公解梦》"
5. **结合现代**：古代解梦需结合现代生活场景重新解读（如"书信"对应现代"消息/邮件"）
