## 核心设计理念

### 8 个心智模型

| 模型 | 一句话 |
|------|--------|
| 经典原文优先 | 古籍原文是 ground truth，评注 ≠ 原文 |
| 象法 vs 理法 | 子平看理法（静态结构），梅花看象法（动态象征）|
| 时间衰减分层 | 大运 10 年 → 流年 1 年 → 流月 1 月 → 流日 1 天，精度递减 |
| 三体系交叉验证 | A+B 一致 > 80%；冲突则调用 C 裁定 |
| 兴衰周期论 | 三元九运定大时代，十二长生定小周期 |
| 五术整合观 | 山医命相卜，分则各家，合则一体 |
| 学习者分级 | 入门白话 + 进阶术语 + 专家原文 |
| 梦象归心 | 情绪优先于符号，万象归心，不制造恐慌 |

### 9 个回答标准

每个体系的回答都有强制性标准模板，不得遗漏必含章节，确保输出质量一致。
